# Demo 2 — Signup leak → funnel

Same cohort, ordered gates, one stage drops hard. The skill should name the **漏斗** and the bottleneck — not a sankey “because it looks advanced.”

## Paste this

```
成長週會要用一張圖講「哪一階掉最多」。這是同一批人依序過關，2026 Q2，示意未核。

| 階段 | 仍在場人數 |
|------|------------|
| 造訪落地頁 | 40000 |
| 完成註冊 | 12000 |
| 開通工作區 | 5400 |
| 首次付費 | 980 |
| 次月續約 | 610 |

問題：哪一階漏損最痛？請用「資料在說什麼」格式推薦圖種，標絕對量與轉換率（寫清分母），點名瓶頸。不要把無關品類塞進漏斗。
```

## You should hear

- **推薦：漏斗圖（funnel）** — 有序階段 + 單調不增的通過量。
- **備選：** 桑基 only if they later add回流／分流；不是現在這張表。
- **避免：** 統計 funnel plot；後階大於前階還硬叫漏斗（本表沒有）。
- Conversion rates with an explicit denominator (e.g. 開通→付費 vs 造訪→付費).
- Bottleneck called out (註冊→開通 or 開通→付費 — either is fine if the math is shown).
- `examples/funnel-stages.md`, 未核, zh-TW.

## Why it wows

The table looks “too simple.” A good answer still writes rates, names a gate, and refuses a decorative sankey.

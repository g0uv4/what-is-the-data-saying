# Demo pack — copy, paste, judge

Five first-run prompts. Each file has a **ready-to-paste block** and the answer shape a stranger can score.

Numbers are **示意／未核**. Do not treat them as a real company.

| # | File | You paste | You should hear |
|---|------|-----------|-----------------|
| 1 | [01-inventory-icicle.md](01-inventory-icicle.md) | Warehouse → category → SKU stock | **冰柱圖（icicle）**, not a pie |
| 2 | [02-signup-funnel.md](02-signup-funnel.md) | Ordered stages that leak | **漏斗圖**, bottleneck named |
| 3 | [03-earnings-waterfall.md](03-earnings-waterfall.md) | Gross profit → signed steps → operating | **瀑布圖（bridge）** |
| 4 | [04-before-after-dumbbell.md](04-before-after-dumbbell.md) | Same stores, H1 vs H2 | **啞鈴圖**, not a slope |
| 5 | [05-two-period-slope.md](05-two-period-slope.md) | Product lines, exactly two periods | **坡度圖**, who steepest |

## How to run

1. `grok plugin install g0uv4/what-is-the-data-saying --trust`
2. Open Grok. Paste the fenced prompt from one file (the block titled **Paste this**).
3. Optional: add `/what-is-the-data-saying` on the first line.
4. Score the reply against **You should hear** in that file.

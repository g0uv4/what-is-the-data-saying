# Examples / pattern library

多數圖種提炼自納茲（資料視覺）教圖；檔內「來源」指向原始檔名（全文不在本 repo）。完整清單見 `../ATTRIBUTION.md`。
第一次安裝請先跑 plugin 根目錄 [`demos/`](../../../demos/README.md) 的五則貼上稿。

# Pattern: connected-scatter

> **圖種**：連接散點圖（Connected scatterplot）
> **來源（納茲教圖）**：`teach-viz/2026-09-04-am-connected-scatter.md`

## When

- 問「兩條時間序列在平面上怎麼一起走」
- 形狀：型 B—X、Y 都是量測；時間只決定連線順序

## Recommend

- **主選**：連接散點圖（型 B）
- **備選**：各畫趨勢 → 雙折線；一般相關 → 散點

## Avoid

- 與型 A（時間在 X 的折線加點）混淆

## Produce checklist

- [ ] 每時點一點依時間連線
- [ ] 標起迄與方向；找 loop／滯後

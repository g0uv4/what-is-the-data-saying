# Pattern: funnel-stages

> **圖種**：漏斗圖（Funnel chart）
> **來源（納茲教圖）**：`teach-viz/2026-09-10-pm-funnel.md`

## When

- 問「同一批對象依序過關，哪一階掉最多」
- 形狀：有序階段 + 各階仍在場／通過數量（通常單調不增）

## Recommend

- **主選**：漏斗圖
- **備選**：多階段流量且可回流／分流複雜 → 桑基；類別重分組 → 沖積

## Avoid

- 後階數量大於前階還硬叫漏斗（口徑錯）
- 與統計 funnel plot（假設檢定）混淆
- 把無關類別塞進漏斗

## Produce checklist

- [ ] 故事句含單位與時間窗
- [ ] 階段順序＝真實流程
- [ ] 標絕對量 + 轉換率（寫清分母）
- [ ] 點名瓶頸階

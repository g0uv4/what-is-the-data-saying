# Pattern: funnel-stages

> **圖種**：漏斗圖（Funnel chart）
> **來源（納茲教圖）**：`teach-viz/2026-09-10-pm-funnel.md`

## When

- 問「同一批對象依序過關，哪一階掉最多」
- 形狀：有序階段 + 各階仍在場／通過數量（通常單調不增）

## Recommend

- **主選**：漏斗圖
- **備選**：多階段流量且可回流／分流複雜 → 桑基；類別重分組 → 沖積

## Avoid

- 後階數量大於前階還硬叫漏斗（口徑錯）
- 與統合分析的漏斗圖（funnel plot，用來檢查發表偏差，見 [`forest-plot.md`](forest-plot.md)）混淆：名字相近、用途完全不同，不要混用、不要併成同一份範例
- 把無關類別塞進漏斗

## Produce checklist

- [ ] 故事句含單位與時間窗
- [ ] 階段順序＝真實流程
- [ ] 標絕對量 + 轉換率（寫清分母）
- [ ] 點名瓶頸階

鄰居 pattern：`forest-plot.md`（森林圖；統合分析的漏斗圖只在該檔作對照，與本檔的商業轉換漏斗圖是不同的圖）。

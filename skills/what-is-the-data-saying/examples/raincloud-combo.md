# Pattern: raincloud-combo

> **圖種**：雨雲圖（Raincloud plot）
> **來源（納茲教圖）**：`teach-viz/2026-09-05-pm-raincloud.md`

## When

- 問「外形 + 個體點 + 摘要同時看」
- 形狀：連續數值 + 少數類別

## Recommend

- **主選**：雨雲圖
- **備選**：只要點 → 蜂群；很多組 → 山脊

## Avoid

- 只要獨立箱／鬚摘要、不要雲＋雨 → 見 `boxplot-summary.md`（箱形圖）

- 只畫 bar+error 卻宣稱看過分布

## Produce checklist

- [ ] 三件齊：雲／雨／傘
- [ ] 標單位與 n

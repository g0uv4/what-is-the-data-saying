## 十件必須釘清的事

1. **怎麼讀（依序）。** 先確認手上是開迴路轉移函數，而且只有一個參數在動（課程稿第 2 節、第 3 節）→ 標開迴路極點（×）與零點（○），軌跡從 × 出發（圖 S1）→ 實軸上，右邊的極點加零點個數是奇數的那一段才屬於軌跡（圖 R2）→ 掃增益，把極點連起來，標幾個增益（圖 S1）→ 標分離點與虛軸交點（圖 R2、圖 R1）→ 需要時疊等阻尼比射線，交點讀增益（圖 S3）。這張圖回答的是「增益調到多少開始振盪、多少變不穩定」。各頻率的分貝與相位，是波德圖的事（[`bode-plot.md`](bode-plot.md)）。離 −1 多遠、繞不繞，是奈奎斯特圖的事（[`nyquist-plot.md`](nyquist-plot.md)）。阻抗離匹配多遠，是史密斯圖的事（[`smith-chart.md`](smith-chart.md)）。三處的做法本稿不重講。根軌跡課程稿沒有列史密斯圖。
2. **名字分開。** 「根軌跡圖」在本課只指增益（或另一個參數）從 0 往上走時，閉迴路極點走的路線。英文 Root locus plot。課程稿的中文主名就是「根軌跡圖」。臺灣官方規範譯名「示範值／未核」，課程稿沒有記載，本稿不另查。中文維基連到的就是〈根軌跡圖〉。極零點圖只放開迴路的 × 與 ○，不掃增益，本 repo 沒有專檔。奈奎斯特圖與波德圖掃的是頻率。史密斯圖掃的是阻抗。參數也可以不是增益：圖 R4 的橫向參數是車速。四個名字不要互換。
3. **它要有轉移函數，而且一次只調一個參數。** 課程稿第 2 節：適合已知輸入到輸出的算式、單參數回授。不適合只有量測到的頻率響應。沒有極點與零點，實軸規則與漸近線就沒有起點。圖 S5 的開迴路本身有一個右半平面極點；這時增益變小不會比較安全。選完增益仍要用時間響應看過一次。時間響應不在這三份 CSV。
4. **做法就是課程稿第 3 節的五步。** (1) 標開迴路極點與零點，起點在 ×。圖 S1、圖 S2、圖 S3 的開迴路是 \(K/(s(s+1)(s+2))\)，增益 0 的極點是 −2、−1、0，沒有有限零點。圖 S4 是 \(K(s+1.5)/(s(s+1)(s+2))\)。圖 S5 是 \(K(s+2)/((s-1)(s+5))\)，增益 0 的極點是 −5 與 +1。(2) 實軸上，測試點右邊的極點與零點總數是奇數，這一段才畫。（3）掃增益，連線，標增益，加方向。（4）標分離點與虛軸交點。（5）疊阻尼比射線。讀的慣例：左半平面穩定，右半平面不穩定，壓在虛軸上持續振盪；越往左衰減越快，離實軸越遠振盪越快；從原點射出的射線是等阻尼比，與負實軸的夾角是反餘弦（阻尼比）。主導極點讀過衝只是估計。
5. **圖 S1、圖 S2、圖 S3 核到的是同一份 201 列。分離點、虛軸交點、漸近線都不是記載的整數。** 欄位是 `K`、`re_1`、`im_1`、`re_2`、`im_2`、`re_3`、`im_3`。沒有空值。增益從 0 到 937.542，嚴格遞增，不重複。說明若寫到 1000，末列不是 1000，自檢把「寫到 1000」印 **NOT CHECKED**。增益 0 的極點是 −2、−1、0。特徵式 \(s^3+3s^2+2s+K=0\)：極點和加 3 的最大絕對差印出 4.000000000070614e-05，兩兩積和減 2 印出 0.00032755850000398823，極點積加增益印出 0.0028973210773983737。殘差不是 0，是存檔短數字留下的。由這三個開迴路極點、沒有有限零點，漸近線中心是 −1，角度規則是 60、180、300 度。末列增益 937.542，極點 −10.8214 與 3.91069±8.44657j；相對中心 −1，實極點是 180 度，複數極點是 ±59.8270199518355 度，不是 60 度。分離點不在某一列上。索引 87（增益 0.380943）仍是三個實極點 −2.15338、−0.47113、−0.375491。索引 88（增益 0.408197）是 −2.1624 與 −0.418801±0.115656j。用這之後頭兩列的虛部平方對增益做兩點外推：增益 0.38461305790181505，實部 −0.4226214290384014，第三極點 −2.1547607569851452。四捨五入到兩位小數是增益 0.38、實部 −0.42，與課程稿「約 −0.42、約 0.38」一致。四位小數的實部是 −0.4226。記載的增益 0.3849 不是這個外推（四位是 0.3846），印 **NOT CHECKED**。虛軸交點在增益 5.63963（實部 −0.0166825、虛部 ±1.37867、第三極點 −2.96664）與 6.04311（實部 0.00195532、虛部 ±1.41836、第三極點 −3.00391）之間，線性內插：增益 6.00078034376338，虛部 ±1.4141960660849822，第三極點 −2.9999999517003597。四捨五入到整數，增益是 6；虛部到兩位小數是 1.41，到四位是 1.4142。記載的增益正好 6 印 **NOT CHECKED**。實部為正的列有 74 列，第一列是索引 127、增益 6.04311。沒有隨機種子。模擬範例資料。

## When

- 已知轉移函數，一次只調一個參數，要看增益到多少開始振盪、到多少不穩定（課程稿第 2 節）
- 要在軌跡上讀某個阻尼比對應的增益（圖 S3）
- 要看加一個零點之後，原本會穿出虛軸的分支還留不留在左半平面（圖 S4）
- 開迴路本身有右半平面極點時，要看增益要大過哪裡才進來（圖 S5）
- 參數不是增益、是車速這類物理量時，仍是同一種圖（圖 R4；43.7 公尺／秒「未核」）
- 情境（課程稿第 7 節，**用法示範，課程稿沒有另附量測出處**）：調馬達位置。疊阻尼比射線，交點取增益。這一檔的阻尼比 0.5 寫增益 1.0375331444568823、極點 −0.3333078113277144±0.5773060637791827j。越靠近虛軸，實部越靠近 0
- **不適合**：只有量測的頻率響應（改奈奎斯特圖或波德圖）。要讀各頻率的分貝與相位（改波德圖）。手上是阻抗或反射係數（改史密斯圖）

# Pattern: scatterplot-matrix

> **圖種**：散布圖矩陣（scatterplot matrix，又稱 pairs plot；縮寫 SPLOM）
> **來源（專案維護者整理）**：`teach-viz/2026-10-14-am-splom.md`（方法教學；第一次以散布圖矩陣為主題。審過的課程終稿就是這次上架用的正文）
> **亦稱**：英文 scatterplot matrix、pairs plot，縮寫 SPLOM。軟體函式名不是另一種圖：seaborn `pairplot`、pandas `plotting.scatter_matrix`、R `pairs`。只要係數的那張是相關熱圖（[`matrix-heatmap.md`](matrix-heatmap.md) 的相關矩陣），不是本圖。只畫一對的是散點圖（[`correlation-scatter.md`](correlation-scatter.md)）。本稿用「散布圖矩陣」。臺灣官方規範譯名，課程稿沒有記載，本稿不另查、**未核**
> **核心**：約三到四個數值變數排成方格，每一格是一對變數的散布；對角線畫該變數自己的分布。一次看相關方向、群聚、離群值。分組要顏色加形狀，不要只靠顏色
> **一句話**：散點圖一次只看一對；相關熱圖只留下係數。散布圖矩陣把值得同時看的三到四欄攤開，先找斜線明顯的格，再看會不會有一個點在很多格一起偏離。
> **誠實提醒**：本課是方法教學。圖 R1–R5 是維基共享資源的公開圖，不是虛構；圖說裡的「分開」「重疊」「偏擠」是課程稿的目視，沒有對原始數據重算。圖 S1、S4、S5 與對應練習檔是虛構，**數字未核**。圖 S2 的底層是公有領域鳶尾花四個數值欄，圖 S3 的底層是 Palmer Penguins（CC0）；這兩份不是虛構亂數，課程稿圖說仍標未核。圖號沿用原編號：參考圖 5 張（R1–R5）＋模擬 5 張（S1–S5），共 10 張。X 原帖只作連結，不當教學依據。課程稿第 8 節三種金屬是通用教學情境，不是真實個案
> **潤稿狀態**：課程終稿與素材包寫明已經審核並潤稿。審稿人的名字本稿不重複。素材包沒有寫出潤稿用哪一個工具，本稿不推測、也不另送潤稿

## 十件必須釘清的事

1. **怎麼讀（依序）。** 先確認是方格、每一格一對數值變數、對角線是單變數分布（直方圖或密度圖，圖 S1）→ 先看斜線明顯的格（正斜＝一起變大，負斜＝一大一小）→ 再看有沒有分成幾團 → 最後找會不會有一個點在很多格同時離開雲團（圖 S5）。這張圖回答的是「哪一對值得再開一張散點圖深挖」，不是「只要一個係數」。係數夠用就改相關熱圖。
2. **名字分開。** 「散布圖矩陣」只指變數兩兩成格、對角線放單變數分布的那張。pairs plot、SPLOM 是同一張圖的英文叫法與縮寫。`pairplot`、`scatter_matrix`、`pairs` 是函式名。相關熱圖的兩軸是變數名稱、格子是一個係數（或一個色塊），沒有原始點。散點圖只有一對軸。滯後圖（[`lag-plot.md`](lag-plot.md)）是同一條序列錯開 k 步，不是不同變數。平行座標（[`parallel-coordinates.md`](parallel-coordinates.md)）是一筆資料穿過多條軸的剖面，課程稿沒有拿它當對照；變數很多、要看每一筆怎麼走，本 repo 用那一檔，不用把七乘七的矩陣硬畫完。
3. **約三到四個數值變數才適合。** 欄再多，格子變小，點看不清（圖 S4 左、圖 R3、圖 R5）。多出來的欄先用相關熱圖篩，挑出三到四欄再重畫矩陣（圖 S4 右）。只要係數、不看形狀，就停在相關熱圖，不必畫矩陣。
4. **構造。** 對角線用直方圖或密度圖。其餘格子畫點。上三角可以改放相關係數（圖 S2）；課程稿沒有規定下三角一定空白，圖 S2 的重點是係數寫在上三角。每一格的兩軸是那一對變數，刻度各算各的。軸名寫全名，不要縮寫（圖 R3）。
5. **分組用顏色加形狀。這是本課要釘住的規則。** 圖 R1、圖 R2、圖 R4 都只用顏色區分組別，**不符合**顏色加形狀的規則。正確示範是圖 S3：三種品種用圓、方、三角，再加顏色。圖 R2 的點全部是方點，組別仍只靠紅、黃、藍，一樣算只用顏色。練習檔的組別在「品種」欄；圓、方、三角是畫圖時加上的，CSV 沒有形狀欄，課程稿也沒有指定哪一個品種用哪一種形狀，本稿不補。
6. **離群值會在多格同時偏離（圖 S5）。** 不要只在一個格子裡找怪點。圖 S5：61 列裡 1 列標記為離群，數值是 (22, 4, 18)。其餘 60 列裡，變數甲最大約 14.2、變數乙最小約 4.5、變數丙最大約 11.7；這個點在甲、丙高於其餘、在乙低於其餘，所以三個兩兩格子都會看到它。圖說的紅叉是畫法，CSV 只記「離群」。
7. **變數太多時，矩陣是反例，熱圖是篩選（圖 S4、圖 R5、圖 R3）。** 圖 S4 是**左右**並排：左邊七個變數的矩陣難讀，右邊改畫相關熱圖再挑變數。不要把圖 S4 說成直式上／中／下。七欄、100 列、非對角 21 對；絕對值最大的是丙與戊，約 0.8067857797701805（虛構，自檢從 CSV 重算）。圖 R5 用九項形狀指標互相做矩陣，只示範格子太多；那九項進階指標**不必先算**。圖 R3 是德文七變數的反例：縮寫難懂，軸名請寫全名；變數縮寫（如 BIS95）**未核**。
8. **圖 R1、圖 R2、圖 R4 是同一份鳶尾花，比的是畫法。** 三張都是四個花部測量。課程稿圖說：圖 R1 紅點（山鳶尾）在花瓣長與花瓣寬那一格明顯分開，綠點與藍點有一部分重疊。圖 R4 的顏色是譜聚類分出的三群，**不是**原始品種標籤；花瓣那一格仍呈正斜。這些都是看圖的說法，沒有對 Anderson／Fisher 的原始表重算。圖 S2 才是把四欄的係數寫進上三角：花瓣長與花瓣寬的皮爾森相關，自檢重算為 0.962865431402796，而且是六對裡絕對值最大的一對。課程稿圖說寫「約零點九六（未核）」。圖 S2 的 CSV **沒有**品種欄，不要把它說成圖 S3 那種分組示範。
9. **圖號不重排；圖 S4 的位置只寫左／右。** 本課嵌入 10 張，編號就是 R1–R5、S1–S5，沒有刪號、不重排。圖 S1 是三變數的矩陣（對角線直方圖；甲與乙正相關約 0.7124228200726517，甲與丙約 −0.056、乙與丙約 0.076，後兩對較散）。圖 S3 是四個測量加品種。圖 S5 是三變數加一個離群點。除了圖 S4 寫明左／右，其餘各圖課程稿沒有說成左右並排，本稿也不改說。
10. **真實圖的出處要寫上；模擬、公開資料與情境不要說混。** 圖 R1–R5 出處與授權見文末。圖 S1、S4、S5 是虛構。圖 S2 是公有領域鳶尾花測量，圖 S3 是 CC0 的企鵝測量；兩張圖是依這些公開表畫的模擬圖，圖上浮水印仍寫數字未核。素材包寫明模擬圖種子 20261014；S2、S3 的數字不是這顆種子造出來的。課程稿第 8 節三種金屬（硬度、密度、導電率）是通用教學情境，不是真實個案。

## When

- 約三到四個數值變數，想一次看兩兩的相關方向、有沒有分成幾團、有沒有離群值（圖 S1、圖 S3、圖 S5）
- 建模之前，想先找出值得再開一張散點圖深挖的那一對（圖 S2 的花瓣長與花瓣寬就是這種一對）
- 已經有組別（品種、金屬種類），而且組別必須在灰階或色覺差異下仍分得開——顏色之外再加形狀（圖 S3）
- 情境（課程稿第 8 節，**通用教學情境，不是真實個案**）：三種金屬，各有硬度、密度、導電率。畫三乘三的矩陣。對角線放直方圖。三種金屬用圓、方、三角，再加三種顏色，圖例寫明形狀與顏色各代表哪一種。先讀斜線明顯的格子，再檢查有沒有一個點在多個格子同時偏離（類似圖 S5）。變數若超過四個，先畫相關熱圖，挑三到四欄再回來畫矩陣（圖 S4）
- **不適合**：變數很多、格子已經小到看不清（圖 S4 左、圖 R3、圖 R5）；讀者只要係數（改相關熱圖）；只有一對變數（改散點圖）；同一條序列錯開 k 步（改滯後圖）；分組只靠顏色（圖 R1、圖 R2、圖 R4 是反例）

## Recommend

- **主選**：三到四個數值變數的散布圖矩陣。對角線用直方圖或密度圖；其餘畫點。有組別時，顏色加形狀一起用，圖例兩欄都寫。上三角若改放相關係數，圖上要寫明那是皮爾森相關（圖 S2）
- **口述步驟**（課程稿第 4 節）：
  1. 先挑三到四欄。欄更多就先畫相關熱圖，挑完再回來（圖 S4）
  2. 對角線用直方圖或密度圖；其餘格子畫點。上三角可以改放相關係數（圖 S2）
  3. 有組別就用顏色加形狀（圖 S3）。不要學圖 R1、圖 R2、圖 R4 只換顏色
  4. 軸名寫全名，單位寫在軸上。圖 R3 那種德文縮寫不要照抄
  5. 讀圖時先看斜線明顯的格，再找多格同時偏離的點（圖 S5）
  6. 模擬圖標「模擬」。虛構數字標未核。公開資料集寫明資料集名稱與授權，不要說成虛構亂數
- **工具誠實**：seaborn `pairplot`、pandas `plotting.scatter_matrix`、R `pairs` 都能畫這種矩陣。以上只列連結，**本 repo 未實測**。素材包說明點名 `draw_splom.py`，本 repo **沒有收**這個腳本，也沒有收任何 png
- **參數與判準範例（範例，不是標準）**：

## 與鄰近圖種的區別

本表依課程稿第 3 節，加上本 repo 已有、課程稿沒有拿來對照的兩檔（滯後圖、平行座標）。除標明出處者外，沒有再逐項查證。圖 S4 的位置只寫左／右。

| 圖種 | 畫什麼 | 本課關係 |
|---|---|---|
| **散布圖矩陣（本稿）** | 三到四個數值變數，兩兩成格，對角線是單變數分布 | — |
| 散點圖（[`correlation-scatter.md`](correlation-scatter.md)） | 只畫一對 | 矩陣裡斜線明顯的那一格，再開這一張深挖 |
| 相關熱圖（[`matrix-heatmap.md`](matrix-heatmap.md) 的相關矩陣） | 變數 × 變數，一格一個係數 | 只要係數，或欄太多時先用它篩（圖 S4 右） |
| 滯後圖（[`lag-plot.md`](lag-plot.md)） | 同一條序列的「前 k 步」對「現在」 | 不是不同變數的矩陣 |
| 平行座標（[`parallel-coordinates.md`](parallel-coordinates.md)） | 一筆資料穿過多條軸 | 變數很多、要看每筆剖面時改這裡；課程稿沒有把這一檔當對照 |

判斷口訣：**約三到四個數值變數、想同時看兩兩的形狀 → 散布圖矩陣；只看一對 → 散點圖；只要係數或欄太多 → 相關熱圖；同一條序列錯開 k 步 → 滯後圖。** 有組別就顏色加形狀（圖 S3）；圖 R1、圖 R2、圖 R4 只用顏色，不要當畫法範本。

## Avoid

- 把圖 R1、圖 R2、圖 R4 當分組的正確畫法（它們只用顏色；圖 R2 雖是方點，三種仍只靠顏色）
- 把圖 S3 的圓、方、三角說成 CSV 裡有形狀欄，或指定某一個品種必用某一形狀（課程稿沒寫）
- 變數超過四個仍把完整矩陣當主圖（圖 S4 左、圖 R3、圖 R5）；九項形狀指標不必先算
- 讀者只要係數仍畫完整矩陣（改相關熱圖）
- 只有一對變數仍稱散布圖矩陣（那是散點圖）
- 把滯後圖或平行座標叫成散布圖矩陣
- 軸名用看不懂的縮寫（圖 R3；BIS95 等縮寫未核）
- 把圖 S4 說成直式上／中／下（課程稿寫左／右）
- 把圖 S2 說成分組示範（CSV 沒有品種欄）
- 把圖 R1、R2、R4 的「分開／重疊」寫成已對原始數據重算
- 把巴布亞企鵝寫成與另外兩種在鰭長或體重上完全分開（自檢：有重疊；圖說是偏右上）
- 把圖 S1、S4、S5 或三種金屬情境說成真實個案
- 把圖 S2、S3 說成虛構亂數（分別是公有領域鳶尾花、CC0 企鵝）
- 把 X 貼文當教學依據（英文 3 則只作連結；中文 0 則，不編造）
- 複製圖檔進 repo，或漏寫作者與授權

## Produce checklist

- [ ] 先確認大約三到四個數值變數；更多就先畫相關熱圖再挑欄（圖 S4）
- [ ] 對角線用直方圖或密度圖；其餘畫點；上三角若放係數，寫明是皮爾森相關（圖 S2）
- [ ] 有組別時顏色加形狀，圖例兩者都寫（圖 S3）；不用圖 R1、R2、R4 的只上色畫法
- [ ] 軸名寫全名與單位（圖 R3 的縮寫是反例）
- [ ] 讀圖順序：斜線明顯的格 → 群聚 → 多格同時偏離的點（圖 S5）
- [ ] 圖 S4 的文字用左／右；圖號維持 R1–R5、S1–S5
- [ ] 圖說分開寫：虛構（S1、S4、S5）、公有領域鳶尾花（S2）、CC0 企鵝（S3）
- [ ] 不嵌入圖檔。引用時保留作者與授權

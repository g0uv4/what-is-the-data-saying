# Pattern: warming-stripes

> **圖種**：升溫條紋圖（Warming stripes）
> **來源（專案維護者整理）**：2026-10-28 上午升溫條紋圖課程稿（方法教學。審過的課程稿就是這次上架用的正文。要讀精確差值，見 [`time-series-trend.md`](time-series-trend.md) 或 [`categorical-comparison.md`](categorical-comparison.md)。一年一列、兩軸都是類別的色格，見 [`matrix-heatmap.md`](matrix-heatmap.md)。氣候螺旋是另一張圖，見 [`spiral-plot.md`](spiral-plot.md)。那幾處的做法本稿不重講。讀完回到本檔）
> **亦稱**：英文 Warming stripes。課程稿又寫氣候條紋圖（climate stripes）。兩詞都是通稱。課程稿寫無官方中文譯名。臺灣官方規範譯名，課程稿沒有記載成已經公告的規範名，本稿不另查政府公報，標「未核」
> **核心**：一年一條。藍是比基準期平均冷，紅是比平均暖。刻意不放數字。色階以 0 為白、正負對稱
> **一句話**：有時間順序、每期一個距平、只要冷暖方向，才畫升溫條紋圖。要讀精確數字，改折線或長條
> **誠實提醒**：本課是方法教學。圖 R1–R4 是公開圖，不是虛構。圖 R1、圖 R2 是 CC BY 4.0（創用 CC 姓名標示），署名 Ed Hawkins（University of Reading，雷丁大學），並連到 [showyourstripes.info](https://showyourstripes.info/)。圖 R3 是 CC0 1.0，署名 Karen Blakeman。圖 R4 是 CC BY-SA 4.0（創用 CC 姓名標示－相同方式分享），原作者 RCraig09；本庫用的是加了中文標籤的改作，改作以 CC BY-SA 4.0 相同方式分享釋出。圖 S1–S5 是本專案自畫，數字是美國國家海洋暨大氣總署全球陸海年均溫距平，基準期標頭是 1901–2000，不是虛構模擬，沒有隨機種子。頁上讀數是練習 CSV 的存檔字串，或由存檔以 `decimal` 重算的全精度（除法有效位數 50）。課程稿與 facts 把 1901–2000 的平均寫成 0.0、把 1991–2020 的平均寫成 0.606，那是記載。1.67、0.415、1.25、42、71、20 由存檔重算後恰好等於記載。標準函式庫自檢把看圖判讀、發表日期、色票名稱、外觀，印成 **NOT CHECKED**。**NOT CHECKED 不計入通過項數。** 圖號沿用原編號：參考圖 R1–R4，練習圖 S1–S5。課程稿第 7 節是用法示範。折線、長條、矩陣熱圖、螺旋圖怎麼畫，見鄰近各檔，本稿不重講

## 十件必須釘清的事

1. **怎麼讀（依序）。** 先寫基準期（圖 S4）→ 色階以 0 為白、正負對稱，半寬用全期絕對值最大（這份資料恰好是 1.25，只有 2024）→ 一年一條、同寬、按年份排 → 要讀兩年差多少，改折線（圖 S2）或長條（圖 S5）。這張圖回答的是「長期是變冷還是變暖」。精確差值是折線與長條的事（[`time-series-trend.md`](time-series-trend.md)、[`categorical-comparison.md`](categorical-comparison.md)）。列×欄的色格是矩陣熱圖的事（[`matrix-heatmap.md`](matrix-heatmap.md)）。把時間捲成一圈一季的氣候螺旋，是螺旋圖的事（[`spiral-plot.md`](spiral-plot.md)）。三處的做法本稿不重講。讀完回到本檔。
2. **名字分開。** 「升溫條紋圖」在本課只指：一條序列、一年一條、顏色表示相對基準期平均的冷暖、刻意不放數字。英文 Warming stripes。課程稿又稱氣候條紋圖（climate stripes），並寫皆為通稱、無官方中文譯名。2018-05-22 這個發表日不在練習 CSV，標「未核」。折線圖讀每一年的高低。長條圖比少數幾年的數字。矩陣熱圖是兩個類別軸交叉成格。氣候螺旋是 Hawkins 2016 年那一類、一圈一個週期的圖，螺旋圖專檔另有自己的基準期例子。地平線圖是很多條序列折成色帶；課程稿沒有拿地平線圖當對照（[`horizon-chart.md`](horizon-chart.md)）。幾個名字不要互換。
3. **它要有時間順序，而且每期只有一個數。** 適合大眾溝通、一眼看方向。不適合沒有先後的類別。不適合要讀精確數值（改 [`time-series-trend.md`](time-series-trend.md) 或 [`categorical-comparison.md`](categorical-comparison.md)，圖 S2、圖 S5）。不適合把一年畫成矩陣裡的一列（那是 [`matrix-heatmap.md`](matrix-heatmap.md)）。並排換基準期時，色階仍用原來的對稱界限，這份資料是 ±1.25；改成各自的最小到最大，高於 0 的年份會被畫到冷色那一側（圖 S3）。
4. **做法是課程稿第 3 節。頁上的量是存檔重算。** (1) 取年均溫距平，寫明基準期。這一檔的來源標頭寫 Base Period: 1901-2000。練習 CSV 只留 `year` 與 `anomaly_c`，基準期寫在圖說，不寫成另一欄。(2) 色階以 0 為白、正負對稱。全期絕對值最大是存檔 `1.25`，只有 2024。對稱界限就是 ±1.25。(3) 按年份排列，每年一條同寬。(4) 疊細線或標年份，讓色弱也讀得懂。細線好不好讀是外觀，標「未核」。美國國家海洋暨大氣總署這一頁是美國政府著作，授權註記寫推定公有領域。練習 CSV 沒有授權欄，公有領域是來源頁的性質，不是從數字算出來的。
5. **圖 S1 核到的是 176 個存檔。看圖判讀沒有核。** 176 列，年份連續 1850 到 2025。唯一最冷是 1917，存檔 `-0.42`。唯一最熱是 2024，存檔 `1.25`。絕對值最大恰為 1.25，只有 2024。距平大於 0 是 71 年，等於 0 是 2 年，小於 0 是 103 年，加總 176。存檔字串 `-0` 只有 1937 與 1947，這兩年的數值是 0。小數位是 159 個兩位、15 個一位、2 個沒有小數點。最小正值是 1938，存檔 `0.01`。facts 的最冷、最熱、色階 1.25、176 年，就是這些存檔。課程稿圖說「前段淺藍、末段幾乎全是深紅」是看圖判讀，印 **NOT CHECKED**。
6. **圖 S2 核到的差恰好是 1.67。外觀沒有核。** 同一份 176 年。`1.25` 減 `-0.42` 是 1.67。百分之一度的差是整數 167，167／100 等於 1.67，小數位恰好兩位。這不是先算出更長的商再四捨五入。課程稿寫「2024 比 1917 高 1.67°C」，數字與存檔一致。課程稿圖說「條紋只說變暖」是外觀，印 **NOT CHECKED**。疊細線以後色弱讀不讀得懂，印 **NOT CHECKED**。折線怎麼畫見 [`time-series-trend.md`](time-series-trend.md)，本稿不重講。
7. **圖 S3 核到的是中點 0.415 與 42 個年份。被畫成藍沒有核。** 最小 `-0.42` 與最大 `1.25` 的中點是 (−0.42+1.25)/2，恰好 0.415，小數位恰好三位。高於 0 且低於 0.415 的年份恰好 42 個：1877、1878、1938、1939、1940、1941、1942、1943、1944、1945、1952、1953、1957、1958、1959、1961、1962、1963、1969、1970、1972、1973、1977、1978、1979、1980、1981、1982、1983、1984、1985、1986、1987、1988、1989、1991、1992、1993、1994、1996、1999、2000。最早 1877，最晚 2000。這是這 42 個年份的起訖，不是 1877 到 2000 每一年。該閉區間裡距平大於 0 的年份是 46 個，不是 42。全期距平大於 0 仍是 71。facts 的 0.415、42、年份範圍 1877 與 2000，就是這個算法。把這 42 年畫成藍色，以及白落在 +0.415 的畫面，印 **NOT CHECKED**。
8. **圖 S4 核到的是兩個窗的平均與偏紅年數。0.0 與 0.606 沒有核成未捨入平均。** 偏紅是平移後的值大於 0。1901–2000 共 100 年，和恰好 0.02，平均恰好 0.0002。記載的 0.0 不是這個平均。減去 0.0002 以後，偏紅 71、零 0、偏藍 105。以名目 0 計，偏紅 71、零 2、偏藍 103。大於 0 的那 71 年沒有因為減去 0.0002 而改類。三分法有變的只有 1937 與 1947：存檔 `-0` 是 0，減去 0.0002 以後小於 0。1991–2020 共 30 年，和恰好 18.17，百分之一度的和是 1817。未捨入平均是 1817/3000。它的小數前三位是 605，其後的 6 無限循環。有效位數 50 的商是 0.60566666666666666666666666666666666666666666666667，末位是進位。記載的 0.606 不是未捨入平均，也不等於這個 50 位的商。減去精確平均以後，偏紅 20、零 0、偏藍 156。1817 不能被 30 整除，所以沒有剛好落在平均上的年份。減去 50 位的商，偏紅仍是 20。減去 0.606，偏紅仍是 20，沒有一年的正負跟精確平均不同。三種平移之後，絕對值仍不大於 1.25：減去 0.0002 的最大絕對值是 1.2498；減去 0.606 的最大絕對值是 1.026；減去精確平均的最大分子是 3077（分母 3000），小於 1.25 的分子 3750。並排時色階可以繼續用 ±1.25。素材另存的第三欄不在這一檔，印 **NOT CHECKED**。圖 R4 的三種基準期不是這份 NOAA 距平，印 **NOT CHECKED**。
9. **圖 S5 核到的是十年存檔。幾乎同色沒有核。** 10 列，2016 到 2025。存檔是 2016 `0.99`、2017 `0.92`、2018 `0.86`、2019 `0.99`、2020 `1.01`、2021 `0.86`、2022 `0.89`、2023 `1.17`、2024 `1.25`、2025 `1.12`。每一筆都是兩位小數，也都大於 0。2016 與 2019 的存檔相同，差是 0。2020 減 2016 恰好 0.02。2018 與 2021 的存檔都是 `0.86`。這十年唯一最大是 2024 的 `1.25`。facts 的十年數字就是這些存檔字串，不是再捨入。課程稿寫「幾乎同色」是外觀，印 **NOT CHECKED**。長條怎麼畫見 [`categorical-comparison.md`](categorical-comparison.md)，本稿不重講。
10. **圖 R1–R4 各有作者與授權。看圖判讀的標保持原句，讀數都不算已核。** 圖 R1 是 CC BY 4.0，署名 Ed Hawkins（University of Reading，雷丁大學），並連 [showyourstripes.info](https://showyourstripes.info/)。授權註記寫縮至 1200 寬，下方加中文註記條。來源頁是維基共享資源的全球條紋。課程稿圖說「前段淺藍、末段幾乎全是深紅」是看圖判讀，標「未核」。圖 R2 同為 CC BY 4.0，同一位作者，同樣連到 showyourstripes.info。授權註記寫縮至 1200 寬，下方加中文註記條。來源頁是臺灣 1901–2019 的條紋。授權註記寫共享資源未寫日期，資料來源與基準期無法確認。課程稿圖說「最右一條最紅」標「看圖判讀」，標「未核」。圖 R3 是 CC0 1.0，署名 Karen Blakeman。授權註記寫縮至 1200 寬，下方加中文註記條；原始 Flickr 頁是攝影頁；攝於 2021-08-04；牆上的條紋設計本身是 Hawkins 的 CC BY 4.0。日期與牆上設計不在練習 CSV，標「未核」。圖 R4 原作者 RCraig09，原出處是維基共享資源那一張三種基準期的比較圖，授權是 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。加了中文標籤，屬改作。改作以 CC BY-SA 4.0 相同方式分享釋出。改動是縮至 1200 寬，三列左上加中文基準期標籤（基準期 1951–1980、基準期 1961–1990、基準期 1971–2000，依檔案說明），下方加註記條。註記寫「同一份資料（柏克萊地球，1850–2018）」與「紫色條＝基準期」。這三種基準期與「基準期越晚，藍色越多」都不是這份 NOAA CSV，標「未核」。漏署名，或漏寫圖 R4 的同方式分享，就與授權不符。

## When

- 有時間順序，每期一個數，想傳達冷暖方向（課程稿第 2 節）
- 基準期寫在圖上，色階以 0 為白、正負對稱（圖 S3、圖 S4）
- 情境（課程稿第 7 節，**用法示範**）：城市百年均溫展覽看板。標起訖年與基準期，色階對稱
- **不適合**：類別沒有先後。要比精確數值（改 [`time-series-trend.md`](time-series-trend.md) 或 [`categorical-comparison.md`](categorical-comparison.md)）。一年一列的色條卻要當矩陣熱圖（[`matrix-heatmap.md`](matrix-heatmap.md)）。讀完回到本檔

## Recommend

- **主選**：升溫條紋圖（Warming stripes）。一年一條。藍冷紅暖。不放數字。寫基準期
- **口述步驟**（課程稿第 3 節，加上圖 S1–S5）：
  1. 取年均溫距平。這一檔寫基準期 1901–2000。圖 S4 若改用 1991–2020，平均寫 1817/3000，不要寫成 0.606
  2. 色階以 0 為白、正負對稱，界限用 ±1.25。不要改成最小到最大
  3. 按年份排，每年一條同寬。圖 S1 的最冷寫 1917、`-0.42`，最熱寫 2024、`1.25`
  4. 要讀差，圖 S2 寫恰好 1.67。1.67 是存檔相減，不是捨入
  5. 圖 S3 若有人把色階改成最小到最大，被放到中點以下的暖年是那 42 個。不要把 1877–2000 說成只有 42 個偏暖年
  6. 圖 S4 的 1901–2000 平均寫 0.0002。0.0 標成記載。偏紅仍是 71，但零年變成 1937 與 1947 的負值。1991–2020 的偏紅寫 20
  7. 圖 S5 的十年寫存檔字串。2016 與 2019 都是 `0.99`，2020 比 2016 高 0.02。「幾乎同色」標「未核」
  8. 圖 R1、圖 R2 署名 Ed Hawkins（University of Reading），CC BY 4.0，並連 showyourstripes.info。圖 R3 署名 Karen Blakeman，CC0 1.0。圖 R4 署名 RCraig09，寫明改作以 CC BY-SA 4.0 相同方式分享釋出。圖 S1–S5 標「美國國家海洋暨大氣總署全球陸海年均溫距平，基準期 1901–2000」

## Avoid

# Pattern: waterfall-bridge

> **圖種**：瀑布圖（Waterfall chart）
> **來源（納茲教圖）**：`teach-viz/2026-09-10-am-waterfall.md`

## When

- 問「從 A 怎麼變成 B、哪一步加減最多」
- 形狀：起點值 + 一串有符號增量／減量 + 終點（可有小計）
- 步數約 4～12 較可讀

## Recommend

- **主選**：瀑布圖／bridge
- **備選**：因子很少且只要兩端差 → 啞鈴；只要兩期誰升誰降 → 坡度圖

## Avoid

- 把中間浮空柱畫成從 0 起的普通長條
- 與堆疊長條／啞鈴／子彈混用同一故事
- 小計不等于前面累加

## Produce checklist

- [ ] 故事句：從〔起點〕到〔終點〕，中間由〔因子〕加減
- [ ] 起點／終點／小計＝落地全高柱；變動＝浮空柱 + connector
- [ ] 增／減分色固定；單位統一
- [ ] 自檢累加與正負色是否跟文字一致

# 圖種啟發式（納茲教圖實戰）

給 **1 主選 + 1–2 備選**。優先選能直接回答問題的最簡單圖；新穎圖種只在資料形狀真的對口時才上。

中文圖種名對齊納茲教圖用語（見 `ATTRIBUTION.md`）。

## 決策表

| 主任務 | 優先 | 備選／注意 |
|--------|------|------------|
| 精確查數、對帳、法規附件 | **表格**（+ 條件格式） | 不要用裝飾圖藏數字 |
| 少數類別比大小 | **長條圖**（標籤長 → 水平） | 高值齊頭要減墨水 → **棒棒糖圖**；圓餅僅 ≤4 塊且敘事需要 |
| 類別很多、要搶眼排序 | **圓形長條圖** | 精準比差距仍回直線長條 |
| 排名／Top-N | **排序長條** | 名次隨時間 → **凹凸圖**；減墨水單值 → **棒棒糖圖** |
| 兩期／兩條件差距 | **啞鈴圖**（Datawrapper Range Plot） | 兩期軌跡交錯感 → **坡度圖** |
| 時間趨勢（少系列） | **折線圖** | 密日資料勿硬用每日長條 |
| 長序列＋穩定週期（季節對齊＋跨年趨勢） | **螺旋圖**（Spiral plot；一圈＝一個週期，角度對齊同一時段；軌道可放長條／折線／色塊） | 只看趨勢或精讀差值 → **折線**；日曆方格紀錄 → **日曆熱力圖**；週期不穩勿用 |
| 時間趨勢（多實體） | **小多圖**（同尺度） | 單圖 20+ 線＝義大利麵 |
| 組成隨時間（整體河） | **河流圖**（Streamgraph／ThemeRiver；亦稱溪流圖） | 精準單層 → 折線／小多圖；貼零總量 → 堆疊面積；階段流向 → 沖積／桑基 |
| 平級組成、少塊 | 堆疊長條／100% 堆疊／**華夫圖** | 區隔規模＋區內組成 → **馬里梅可圖**；階層 → 下面階層列 |
| 階層組成、要標籤 | **冰柱圖** | 緊湊總覽 → **旭日**；鋪滿面積 → **矩形樹狀**；嵌套圓 → **圓堆**；凸多邊形鋪滿 → **Voronoi 樹狀** |
| 從 A 到 B 的因子橋 | **瀑布圖**（bridge） | 不要跟啞鈴／堆疊長條混 |
| 階段漏損／轉換率 | **漏斗圖** | 後階 > 前階 → 口徑錯或非漏斗 |
| 有向流量（過程） | **桑基圖** | 有序階段重分組 → **沖積圖** |
| 成對雙向交換 | **弦圖** | 不要拿來畫階層組成 |
| 兩數值關係 | **散點** | ＋第三量級 → **氣泡圖**（面積映射）；過密 → **六角分箱**／**等高線** |
| 雙序列怎麼一起演化 | **連接散點圖**（型 B：雙量測平面） | 勿與「時間在 X 的折線加點」混淆 |
| 相關／矩陣強度（列 × 欄哪裡熱） | **矩陣熱圖**（Heatmap；循序色階，有中點用發散；可標註或分群重排） | 網路有無邊 → **鄰接矩陣**；日曆版面每日一值 → **日曆熱力圖**；成對交換 → **弦圖**；精確比少數值 → 排序長條 |
| 分布形狀（少組） | **箱形圖**（五數＋離群；並排多組）／**小提琴**／**雨雲**／**蜂群** | 多組密度漂移 → **山脊圖**；要密度／雙峰勿只給純箱 |
| 多類別交叉表（獨立性／列聯） | **馬賽克圖** | 商用區隔×組成 → **馬里梅可圖**；多維頻率帶 → **平行集合** |
| 集合交集（多集合） | **UpSet** | 不要用一堆 Venn |
| 多連續特徵剖面 | **平行座標** | 少度量、要比外形 → **雷達**（系列 ≤2～3） |
| 三組成加總常數 | **三元圖** | 非三元勿硬套 |
| KPI 實際 vs 目標＋區間 | **子彈圖** | 不要用圓形儀表取代長度比較 |
| 專案時程 | **甘特圖** | 依賴箭頭少畫 |
| 日活動密度 | **日曆熱力圖** | 勿與類別矩陣熱力混淆 |
| 網路誰連誰 | **力導向**；要可讀標籤 → **弧線圖**；要比兩張網 → **蜂巢圖** | 有可信階層＋葉連線 → **階層式邊捆綁（HEB）** |
| 地理比率 | **等值區域圖**（choropleth；先正規化：比率／每人／每面積；總量勿填色） | 計數疏密／叢集 → **點密度圖**；總量點位規模 → **比例符號地圖**；面積＝資料量 → **統計變形地圖**；起迄 → **流量地圖** |
| 各區同等權重的比率／類別（怕大區搶眼） | **圖塊地圖**（Tile map；一區一格、格子等大，照方位排） | 要真實邊界 → **等值區域圖**；格數＝人口／選舉人票 → 加權六角／方塊（屬**統計變形地圖**）；少數區比高下 → 排序長條 |
| 年齡×雙側結構輪廓 | **人口金字塔**（Split／Mirror Bars） | 單側比大小 → 長條；敏感度正負排序 → 龍捲風；歷年組成 → 堆疊面積／時序 |
| 同結構多切片 | **小多圖** | 軸尺度要對齊 |

## 形狀 → 圖捷徑

- **時間 + 1 數值 + ≤3 系列** → 折線
- **類別 + 1 數值** → 長條（多類別搶眼 → 圓形長條；減墨水／高值齊頭 → 棒棒糖）
- **類別 + 兩個同單位數值** → 啞鈴
- **可排序年齡組 + 雙側度量（人數／占比）** → 人口金字塔
- **實體 + 恰好兩期數值** → 坡度圖
- **時間 + 實體 + 可排名度量** → 凹凸圖
- **時間 + 類別 + 非負量（整體組成／流動感）** → 河流圖（溪流圖）；要貼零讀累加總量 → 堆疊面積
- **2 數值** → 散點；**2 數值＋第三量級（非負 size）** → 氣泡圖（面積映射，勿映半徑）；點重疊嚴重 → hexbin／contour
- **2 數值 + 時間只決定連線順序** → 連接散點
- **類別 × 類別 + 值** → 矩陣熱圖（先檢查各欄尺度，必要時依欄／列正規化）／馬賽克（獨立性）；**外層區隔 + 內層組成 + 可加總量（欄寬＝規模）** → 馬里梅可
- **path／父子 + 數值** → 冰柱／旭日／treemap／圓堆／Voronoi 樹狀
- **起點 + 有符號增量串** → 瀑布
- **有序階段 + 通過量（單調不增）** → 漏斗
- **來源→去向 + 流量** → 桑基；階段重分組 → 沖積；方陣交換 → 弦圖
- **節點 + 邊** → 力導向／弧線／鄰接矩陣；+階層葉連線 → HEB
- **類別 + 連續數值（多組分布摘要）** → 箱形圖；要密度／雙峰 → 小提琴；雲＋雨＋傘 → 雨雲；每點 → 蜂群
- **每日一值** → 日曆熱力
- **長時間序列（數年以上）+ 穩定週期（12 月／52 週／7 天／24 小時）** → 螺旋圖（一圈＝一週期）；只看趨勢 → 折線
- **任務 + 開始 + 結束** → 甘特
- **實際 + 目標 + 質性區間** → 子彈
- **geo 區塊 + 比率** → choropleth；**geo 區塊 + 可數計數疏密** → 點密度圖（一對多）；**真實 lat/lon 落點** → 點密度／標記圖（一對一）；**點 + 總量規模（地圖）** → bubble map／比例符號；**笛卡兒 X／Y＋第三 size** → 氣泡圖（非地圖）；**起迄流向** → flow map

## 易混圖種（納茲口訣摘錄）

| 不要混 | 差在哪 |
|--------|--------|
| 冰柱 vs 旭日 | 同一套 partition；冰柱＝直角深度軸好標字；旭日＝環帶緊湊 |
| 冰柱／旭日 vs 桑基 | 隸屬組成 ≠ 有向流量 |
| 啞鈴 vs 坡度圖 | 啞鈴＝類別列上兩點差距；坡度＝兩垂直軸軌跡 |
| 啞鈴 vs 棒棒糖 | 棒棒糖一端在基線；啞鈴兩端互連 |
| 棒棒糖 vs 長條 | 同任務；棒棒糖＝細莖+點減墨水；要面積感／不熟點圖 → 長條 |
| 棒棒糖 vs 無莖點圖／Cleveland | 有自基線細莖＝本課棒棒糖；僅點無莖＝點圖鄰居 |
| 棒棒糖 vs 誤差棒／子彈 | 單值相對基線 ≠ 不確定區間 ≠ KPI 目標量表 |
| 人口金字塔 vs 普通長條／直方 | 左右鏡像＋年齡軸輪廓 ≠ 單向類別比大小 |
| 人口金字塔 vs 龍捲風／蝴蝶 | 年齡人口結構 ≠ 敏感度／正負因子排序 |
| 人口金字塔 vs 山脊／小提琴 | 離散年齡組對稱條 ≠ 連續密度形狀 |
| 人口金字塔 vs OWID 年齡時序堆疊 | 單年金字塔截面 ≠ 歷年組成演變 |
| 圓形長條 vs 南丁格爾玫瑰 | 棒長 vs 等角扇形面積（半徑常對平方根） |
| 圓形長條 vs 雷達 | 獨立棒 vs 多軸連多邊形 |
| 螺旋圖 vs 圓形長條 | 連續時間捲成多圈、圈間對齊季節 ≠ 類別繞一圈就結束 |
| 螺旋圖 vs 雷達／南丁格爾玫瑰 | 時間序列週期對齊 ≠ 多變量或分類占比的封閉形狀 |
| 螺旋熱圖 vs 日曆熱力圖／矩陣熱圖 | 格子嵌在螺旋弧段、一圈＝一週期 ≠ 日曆方格牆／任意行列 |
| 螺旋圖 vs 折線／河流圖／甘特 | 把過長時間軸捲起來凸顯週期重疊 ≠ 水平線性時間軸（精讀差值回折線） |
| 螺旋圖 vs 地平線圖 | 地平線可當螺旋軌道上的一種編碼，本身不等於螺旋圖 |
| 螺旋「一圈」定義 | 一圈＝一個週期（例：一年，角度＝月份）；「一圈＝一個月」是常見誤寫 |
| 蜂群 vs 蜂巢圖 | 一維數值避撞排點 vs 放射軸網路 |
| 雨雲 vs 山脊 | 少組＝雲+雨+箱 vs 多組密度山脈 |
| 箱形 vs 小提琴 | 五數摘要＋離群 ≠ 完整密度／雙峰外形 |
| 箱形 vs 雨雲 | 獨立箱／鬚 ≠ 雲＋雨＋傘複合 |
| 箱形 vs 蜂群 | 摘要為主（預設只點離群）≠ 每個觀測點可見 |
| 箱形 vs 直方／密度 | 多組並排省版面 ≠ 單組細形狀 |
| 箱形 vs 長條／棒棒糖 | 類別×整組分布 ≠ 類別×單一彙總值 |
| 箱形 vs 誤差棒 | 樣本內分布摘要 ≠ 抽樣推論不確定性 |
| 沖積 vs 桑基 vs 平行集合 | 有序階段重分組 vs 自由節點流量 vs 等長類別軸頻率帶 |
| 河流圖 vs 堆疊面積 | 浮動中心／wiggle 基準 vs 貼齊 y＝0；後者可當總量尺 |
| 河流圖 vs ThemeRiver | 同家族：ThemeRiver≈對稱中軸剪影；Streamgraph≈減晃動演算法排序 |
| 河流圖 vs 山脊線 | 同一河道內厚度堆疊 vs 多序列上下錯開密度 |
| 河流圖 vs 沖積／桑基 | 連續時間組成厚度 vs 階段節點＋轉移帶 |
| 河流圖 vs 面積圖（單層） | 多類別組成河 vs 單一填色曲線下方面積 |
| 河流圖（viz）vs 投資「河道／本益比」用語 | 完全不同概念，勿混案例 |
| 力導向 vs 弧線 vs 鄰接矩陣 | 佈局說話但難標全名 vs 線性好標 vs 矩陣可重排看團 |
| HEB vs 力導向邊捆 | HEB 沿**階層共同祖先**捆；FDEB 無階層 |
| hexbin vs 日曆熱力 vs 鄰接矩陣 | 兩連續軸密度格 vs 日曆骨架 vs 節點×節點 |
| 矩陣熱圖 vs 日曆熱力圖 | 任意兩個類別／有序軸（含星期 × 小時）≠ 日曆版面（週 × 星期、按月排）的每日一值 |
| 矩陣熱圖 vs 鄰接矩陣 | 兩軸可不同、格子＝數值強度 ≠ 兩軸同一組網路節點、格子＝邊，排序是分析核心 |
| 矩陣熱圖 vs 弦圖 | 讀每格強度 ≠ 同一方陣畫成圓周交換帶 |
| 矩陣熱圖 vs 馬賽克／馬里梅可 | 等大格子、顏色編碼數值 ≠ 面積編碼占比 |
| 相關矩陣色塊 vs 相關散點示意 | 變數 × 變數格子上發散色（Wilke forensic glass 例）≠ 散點圖示意相關係數大小 |
| 矩陣熱圖分群重排 vs 固定順序 | 要看相似才重排（clustermap＋樹狀圖）；時間、等級軸保持原序 |
| Voronoi 樹狀 vs 地圖 | 面積＝權重，外框不是地理邊界 |
| 統計變形地圖 vs choropleth | 面積被資料撐大／縮小 vs 邊界固定只填色 |
| 點密度圖 vs 比例符號／氣泡地圖 | 等大點的**數量／疏密** vs 單點（區）**面積∝總量** |
| 點密度圖 vs choropleth | 計數灑點／落點 vs 多邊形填色（多為比率） |
| 點密度圖 vs hexbin／等高線／density2d | 地理底圖上等大點 vs 非地理兩軸密度格／等值線 |
| 等值區域圖 vs 比例符號地圖 | 已正規化比率整區填色 ≠ 總量畫在點上圓（面積∝總量）；總量勿填色 |
| 等值區域圖 vs 流向地圖 | 靜態區域指標 ≠ 起迄方向線 |
| 等值區域分級：分位數 vs 等距 vs 自然斷點 | 每級區數相同（易放大小差） vs 每級數值寬相同（偏態擠一級） vs 依資料群聚切；圖例寫明 |
| 等值區域色階：順序 vs 發散 | 單向高低 ≠ 有意義中心值（0／平均／目標）兩端分色 |
| 等值區域大面積低人口偏誤 | 地廣人稀區奪眼、小而人多區看不見 → 註明「色＝比率」；並列 cartogram／圖塊地圖／排序長條 |
| 圖塊地圖 vs 等值區域圖 | 一區一格等大（解大面積偏誤，形狀與鄰接失真）vs 真實邊界面積填色 |
| 圖塊地圖 vs 加權六角／方塊（grid cartogram、electoral college hexagons、鑲嵌式面積變形地圖、Tilegrams） | 每區恰一格 ≠ 格數＝人口／選票（屬統計變形地圖） |
| 圖塊地圖 vs hexbin | 每格＝具名行政區 ≠ 點資料聚合網格（無區名）；R Graph Gallery「hexbin map of the USA」實為一州一格 |
| 圖塊地圖 vs 矩陣熱力 | 排法須看得出地理輪廓 ≠ 純類別欄列 |
| 點密度一對多 vs 一對一 | 多邊形內演算法配置（1 點＝N）vs 真實座標一點一筆（Snow 類屬後者） |

| 氣泡圖 vs 比例符號／bubble map | 笛卡兒 X／Y＋面積＝第三量級 ≠ 圓心在地理經緯 |
| 氣泡圖 vs 普通散點 | 有第三 size（面積映射）≠ 點大小固定／無第三維 |
| 氣泡圖 vs 連結散點 | 單截面一實體一圓 ≠ 多期折線軌跡 |
| 氣泡圖 vs 圓堆／Treemap | 有 X／Y 關聯軸 ≠ 階層／組成面積鋪滿（無關聯軸） |
| 氣泡圖 vs hexbin／等高線 | 每實體可辨氣泡 ≠ 海量點密度聚合 |
| 氣泡面積 vs 半徑／直徑 | 必須面積映射；直徑×2＝面積×4，勿當數值 |

| 馬里梅可 vs 馬賽克圖 | 商用變寬堆疊（區隔規模×區內組成）≠ 統計列聯／獨立性殘差主線 |
| 馬里梅可 vs 等寬堆疊／100% 堆疊 | 欄寬本身是資訊 ≠ 欄寬固定 |
| 馬里梅可 vs Treemap | 外層類別沿軸、寬度＝邊際占比 ≠ 階層面積嵌套（無欄寬軸敘事） |
| 馬里梅可 vs Variwide | 雙維區隔×組成 ≠ 常為單系列變寬長條 |
| 馬里梅可百分比軸 vs 絕對值軸 | 每欄高固定 100%／比結構 ≠ 欄高隨單位量變／比絕對堆疊 |

## 編碼規則（短）

- 數量：位置 > 長度 > 角度 > 面積 > 色相。
- 一個主問題一個主編碼。
- 雙軸：僅在使用者堅持時；兩軸都標清楚；寧可指數化／雙面板。
- 堆疊絕對值：看總量+粗組成可以；比中段 → 分組長條或 100% 堆疊 + 旁表。
- 圓／面積編碼：旁邊準備表格或改長條給要精準比的人。

# 圖種啟發式（專案維護者整理）

給 **1 主選 + 1–2 備選**。優先選能直接回答問題的最簡單圖；新穎圖種只在資料形狀真的對口時才上。

中文圖種名對齊專案維護者整理的用語（見 `ATTRIBUTION.md`）。

## 決策表

| 主任務 | 優先 | 備選／注意 |
|--------|------|------------|
| 精確查數、對帳、法規附件 | **表格**（+ 條件格式） | 不要用裝飾圖藏數字 |
| 少數類別比大小 | **長條圖**（標籤長 → 水平） | 高值齊頭要減墨水 → **棒棒糖圖**；圓餅僅 ≤4 塊且敘事需要 |
| 類別很多、要搶眼排序 | **圓形長條圖** | 精準比差距仍回直線長條 |
| 排名／Top-N | **排序長條** | 名次隨時間 → **凹凸圖**；減墨水單值 → **棒棒糖圖** |
| 一堆類別、要找「先處理哪幾項」（原因、問題、客訴、停機機台），既看每類大小又看前幾類累計占比 | **柏拉圖**（`examples/pareto-chart.md`；直條由大到小＋累計百分比折線、右軸 0–100%、左軸最大值＝總數；「其他」通常放最右；80/20 只是經驗法則，看累計線第一次到達或越過 80% 是第幾項） | 各類差不多大或只有兩三類 → 一般長條圖；要看趨勢 → 折線或管制圖（`examples/control-chart.md`）；要證明因果 → 另查原因；起點到終點的增減 → 瀑布圖 |
| 兩期／兩條件差距 | **啞鈴圖**（Datawrapper Range Plot） | 兩期軌跡交錯感 → **坡度圖** |
| 時間趨勢（少系列） | **折線圖** | 密日資料勿硬用每日長條 |
| 長序列＋穩定週期（季節對齊＋跨年趨勢） | **螺旋圖**（Spiral plot；一圈＝一個週期，角度對齊同一時段；軌道可放長條／折線／色塊） | 只看趨勢或精讀差值 → **折線**；日曆方格紀錄 → **日曆熱力圖**；週期不穩勿用 |
| 時間趨勢（多實體） | **小多圖**（同尺度） | 單圖 20+ 線＝義大利麵 |
| 時間趨勢（很多條、列高很矮、要掃相對基準的偏離與同步衝擊） | **地平線圖**（`examples/horizon-chart.md`；相對基準的面積切成等高色帶疊回矮條；基準寫在圖說；2 帶為主；跨列比較要共用帶寬） | 只有一到三條或要讀精確值 → 折線＋游標；圖夠高（約 24 像素以上）→ 折線小多圖；矮條高度不是真實振幅 |
| 時間趨勢＋要判斷流程穩不穩、哪個點該查原因（尺寸、不良率、缺陷數、實驗室品管值） | **管制圖**（`examples/control-chart.md`；點依時間順序＋中心線＋上下管制界限；界限由流程資料算出，不是規格；事先約定判異規則——連續同側 Western Electric 8 點、Nelson 9 點） | 只想看趨勢 → 折線圖；排類別貢獻 → 柏拉圖；看分布形狀 → 直方圖；要判斷合不合規格 → 規格線另畫 |
| 一群個體（人、家戶、客戶、國家）有非負可加總的數量，想看最貧（最小）X% 合計占多少、分配形狀、兩群體誰較不均（所得、財富、營收） | **洛倫茲曲線**（`examples/lorenz-curve.md`；單位由小到大排序、兩軸都是累計百分比、附對角線；基尼係數註明有沒有乘 n／(n−1) 的小樣本修正；一人全拿 10 戶是 0.90 不是 1；兩群體先看有沒有交叉） | 類別排名、前幾類累計 → 柏拉圖；流程穩不穩 → 管制圖；時間趨勢 → 折線；有負值先處理 |
| 一條可排成一維順序的路線上有多班車（列車、公車），每班車在每站有到離站時刻，想同時看速度、停站、班距、超車與會車、計畫對實際、串車 | **馬雷圖／列車運行圖**（`examples/marey-chart.md`；橫軸時刻、縱軸依實際距離排站、每班一條線；斜率＝速度、水平段＝停站、交叉＝相遇或超車；單線區間交叉須落在能會車的站內） | 單一指標隨時間 → 折線；工作起訖 → 甘特圖；縱軸排不出一維順序 → 地圖或流量地圖；班次太多先拆圖 |
| 每個人（零件、客戶）有觀察時間與事件／設限狀態，想看群體撐多久、中位存活、兩組差距隨時間怎麼變 | **存活曲線／Kaplan–Meier**（`examples/kaplan-meier-survival.md`；階梯、設限短直線、信賴區間、風險人數表） | 單一指標隨時間 → 折線；風險比點估計無時間軸 → 森林圖；有競爭風險 → 累積發生率；每人一條軌跡 → 游泳圖 |
| 每位受試者一條觀察到的時間區間＋事件符號，想看個人撐多久、反應何時出現、停止原因、誰仍在，約 50 人以內 | **游泳圖**（`examples/swimmer-plot.md`；一人一橫棒、依長度排序、符號＋棒尾箭頭、註明截止日） | 族群存活比例 → Kaplan–Meier；計畫工作起訖 → 甘特；分工流程 → 泳道流程圖；腫瘤縮小幅度 → 瀑布圖；腫瘤大小隨時間 → 蜘蛛圖 |
| 很多個體 × 共同等距時間點、每格一個數值或類別，想同時看個人與整群、缺值樣貌 | **千層麵圖（lasagna plot，暫譯）**（`examples/lasagna-plot.md`；一列一人、排序寫明、單色固定範圍、缺值另標、加平均折線） | 要精準讀值或時間不等距 → 義大利麵圖／折線；事件與持續時間 → 游泳圖；欄不是時間 → 一般熱圖；只有一個對象 → 日曆熱圖 |
| 一條等距時間序列，想看何時回到相近狀態、週期／停滯／突變／漂移，或兩條序列的同步 | **遞迴圖（recurrence plot，暫譯）**（`examples/recurrence-plot.md`；時間×時間黑白方陣；寫明 ε、m、τ；可加 RQA／交叉遞迴圖） | 看數值高低 → 折線；很多人×時間的量測 → 千層麵圖；列欄不是時間 → 一般熱圖／鄰接矩陣 |
| 聲音、振動、腦波等快速振盪訊號，想看什麼時間出現哪些頻率、各多強 | **頻譜圖（spectrogram）**（`examples/spectrogram.md`；時間 × 頻率 × 顏色＝分貝；圖上寫六項設定；0 分貝基準要寫明；避免彩虹色） | 只看整段平均 → 頻譜；慢速無振盪 → 折線；立體堆疊 → 三維瀑布圖（不是財務瀑布圖）；縱軸是尺度 → 小波量值圖 |
| 一條等距時間序列，想看隔幾步還跟自己有關（週期、趨勢、殘差像不像白噪音） | **自相關圖（autocorrelation plot）**（`examples/autocorrelation-plot.md`；橫軸滯後、縱軸係數，滯後 0＝1；固定寬度 ±1.96／√n 或 Bartlett 變寬帶；圖上寫明公式與軟體預設） | 兩軸是變數名稱 → 相關矩陣；只看數值高低 → 折線；何時回到相近狀態 → 遞迴圖；什麼時間有哪些頻率 → 頻譜圖 |
| 組成隨時間（整體河） | **河流圖**（Streamgraph／ThemeRiver；亦稱溪流圖） | 精準單層 → 折線／小多圖；貼零總量 → 堆疊面積；階段流向 → 沖積／桑基 |
| 平級組成、少塊 | 堆疊長條／100% 堆疊／**華夫圖** | 區隔規模＋區內組成 → **馬里梅可圖**；階層 → 下面階層列 |
| 階層組成、要標籤 | **冰柱圖** | 緊湊總覽 → **旭日**；鋪滿面積 → **矩形樹狀**；嵌套圓 → **圓堆**；凸多邊形鋪滿 → **Voronoi 樹狀** |
| 效能剖面：時間耗在哪些呼叫路徑（堆疊取樣） | **火焰圖**（Flame Graph；寬＝合併後樣本占比、高＝堆疊深度、橫軸字母排序非時間） | 要呼叫的時間順序／空隙 → **火焰時序圖**（Flame Chart）；一般階層組成 → **冰柱圖**；只有扁平計數 → 長條／表；CPU 不忙但延遲高 → Off-CPU 火焰圖 |
| 從 A 到 B 的因子橋 | **瀑布圖**（bridge） | 不要跟啞鈴／堆疊長條混 |
| 階段漏損／轉換率 | **漏斗圖** | 後階 > 前階 → 口徑錯或非漏斗 |
| 有向流量（過程） | **桑基圖** | 有序階段重分組 → **沖積圖** |
| 成對雙向交換 | **弦圖** | 不要拿來畫階層組成；有位置刻度軸＋多軌 → **Circos** |
| 長刻度參考軸（染色體等）＋沿軸多層訊號＋兩位置對位 | **Circos**（環狀多軌圖；環＝參考軸、軌道＝同位置多層、連線／寬帶＝對位） | 只有類別流量 → **弦圖**／桑基；要精確數值 → 線性多軌圖／表；只看沿軸分佈 → 多軌、中心留白 |
| 兩數值關係 | **散點** | ＋第三量級 → **氣泡圖**（面積映射）；過密 → **六角分箱**／**等高線** |
| 差異分析結果：每個特徵的效應量＋p 值（上千特徵，要排優先順序） | **火山圖**（Volcano plot；橫軸 log2 倍數變化、縱軸 −log10 p 值，寫明原始或校正後；門檻虛線＋三／四色；門檻為範例，不是標準） | 橫軸是基因體位置 → **曼哈頓圖**；看表現量層級偏差 → **MA 圖**（診斷，可並列）；任意兩欄 → 一般**散點** |
| 全基因組關聯訊號落在哪一號染色體、哪一段（標記＋染色體＋位置＋p 值） | **曼哈頓圖**（Manhattan plot；橫軸依染色體排列的基因組位置、縱軸 −log10(p)、相鄰染色體交替色、事先約定門檻線；門檻為範例，不是標準） | 兩性狀比較 → **邁阿密圖**（上下鏡像變體）；p 值整體膨脹 → **QQ 圖**；單一峰值附近 → **LocusZoom 圖**（`examples/locuszoom.md`）；橫軸是效應量 → **火山圖** |
| 兩條件比較的診斷：在什麼豐度層級上變、正規化或收縮是否異常（平均表現＋對數倍數） | **MA 圖**（MA plot；橫軸 A 平均表現、縱軸 M 對數倍數、畫 M＝0；顏色寫明是檢定結果還是單純門檻；門檻為範例，不是標準） | 要候選排序 → **火山圖**；橫軸是位置 → **曼哈頓圖**；整數計數＋零計數點 → **RA 圖**（軸語意同 MA 圖）；兩種量測方法的一致性 → **Bland–Altman 圖**（`examples/bland-altman.md`；用途不同，不是同一種圖） |
| 分布形狀像不像某個參考分布／兩批像不像同一種分布（或 GWAS p 值整體有沒有偏離期望） | **QQ 圖**（Q–Q plot；分位數對分位數；註明參考線是 y = x、四分位線或擬合線；不是假設檢定，沒有 p 值；小樣本要保守） | 累積機率曲線是否重合 → **P–P 圖**（`examples/pp-plot.md`）；只想看輪廓 → 箱形／小提琴／山脊；兩種量測方法一致性 → **Bland–Altman 圖**（`examples/bland-altman.md`）；局部區間 → **LocusZoom 圖**（`examples/locuszoom.md`）；位置 → **曼哈頓圖** |
| 同一個數值上，兩邊（樣本對完全指定的理論分布，或兩批位置相近的樣本）的累積機率像不像 | **P–P 圖**（P–P plot；機率—機率圖；橫軸理論累積機率、縱軸樣本累積機率〔本 repo 慣例，各來源不一致，圖題要寫〕，兩軸 0 到 1、加對角線、等軸比例；繪點公式要寫；中央較敏感是定性說法，不是定理） | 分位數對分位數、講尾巴與離群 → **QQ 圖**；軸是數值的 NIST「Probability Plot」、SciPy `probplot` → 不是 P–P；兩種量測方法一致性 → **Bland–Altman 圖**；位置對 −log10(p) → **曼哈頓圖**／**LocusZoom 圖** |

| 網路誰連誰 | **力導向**；要可讀標籤 → **弧線圖**；要比兩張網 → **蜂巢圖** | 有可信階層＋葉連線 → **階層式邊捆綁（HEB）**；稠密成毛球 → **BioFabric** |
| 稠密網路、每條邊都要可辨識／比連線型態／邊依類型・條件・時間分塊 | **BioFabric**（生物織布圖，暫譯；節點＝水平列、邊＝垂直欄） | 節點少邊稀疏 → **力導向**／**弧線**；只要有無矩陣熱讀 → **鄰接矩陣**；份額／流量 → 桑基／沖積／弦圖；精確邊權重 → 表 |
| 地理比率 | **等值區域圖**（choropleth；先正規化：比率／每人／每面積；總量勿填色） | 計數疏密／叢集 → **點密度圖**；總量點位規模 → **比例符號地圖**；面積＝資料量 → **統計變形地圖**；起迄 → **流量地圖** |
| 各區同等權重的比率／類別（怕大區搶眼） | **圖塊地圖**（Tile map；一區一格、格子等大，照方位排） | 要真實邊界 → **等值區域圖**；格數＝人口／選舉人票 → 加權六角／方塊（屬**統計變形地圖**）；少數區比高下 → 排序長條 |
| 年齡×雙側結構輪廓 | **人口金字塔**（Split／Mirror Bars） | 單側比大小 → 長條；敏感度正負排序 → 龍捲風；歷年組成 → 堆疊面積／時序 |
| 同結構多切片 | **小多圖** | 軸尺度要對齊 |

## 形狀 → 圖捷徑

- **時間 + 1 數值 + ≤3 系列** → 折線
- **類別 + 1 數值** → 長條（多類別搶眼 → 圓形長條；減墨水／高值齊頭 → 棒棒糖）
- **類別 + 件數或金額 + 想知道前幾類累計占多少（原因貢獻排序）** → 柏拉圖（左軸最大值＝總數；「其他」通常放最右；金額與件數的排名可能不同）
- **同一指標依時間／子組順序 + 想判斷流程穩不穩** → 管制圖（依資料型態選 X̄–R、X̄–S、I–MR、p、np、c、u；界限由資料估，不是規格；先約定判異規則）
- **一群個體各有一個非負數量 + 想看最貧 X% 占多少或不均程度** → 洛倫茲曲線（單位由小到大排、兩軸累計百分比；基尼註明算法與有無小樣本修正；曲線交叉就分段描述、不只比基尼）
- **一條一維路線 + 多班車的到離站時刻 + 想看速度、會車、超車、誤點或串車** → 馬雷圖（站點依實際距離排；每班一條線；圖面寫「約」時附精確值；太密就拆圖）
- **觀察時間 + 事件／設限（可加分組）+ 想看群體撐多久** → Kaplan–Meier 存活曲線（設限正確處理；交叉時分段；尾端看風險人數；縱軸截斷要明講）
- **每位受試者 + 開始／結束（或時長）+ 事件時間 + 停止原因 + 是否仍在** → 游泳圖（約 50 人以內；依長度排序；超過改 KM 或分面）
- **個體 × 共同等距時間點 + 每格數值或類別（可有缺值、分組）** → 千層麵圖（每列約 10 像素以上；人多分組或改比例版；缺值不補 0）
- **一條等距時間序列 + 想看何時回到相近狀態（可加第二條做交叉）** → 遞迴圖（試幾個門檻；圖上寫 ε、m、τ；決定性高不是規律的充分條件）
- **快速振盪訊號（聲音、振動、腦波）+ 已知固定取樣率 + 想看什麼時間有哪些頻率** → 頻譜圖（先濾掉高於取樣率一半的成分；圖上寫六項設定；分貝要寫基準；比較時固定設定）
- **一條等距時間序列 + 想看隔幾步還跟自己有關（週期、趨勢、殘差白噪音）** → 自相關圖（滯後 0＝1；寫明信心帶公式；緩慢衰減先差分；偏自相關定階只是起點；correlogram 第二義＝相關矩陣）
- **類別 + 兩個同單位數值** → 啞鈴
- **可排序年齡組 + 雙側度量（人數／占比）** → 人口金字塔
- **實體 + 恰好兩期數值** → 坡度圖
- **時間 + 實體 + 可排名度量** → 凹凸圖
- **時間 + 類別 + 非負量（整體組成／流動感）** → 河流圖（溪流圖）；要貼零讀累加總量 → 堆疊面積
- **2 數值** → 散點；**2 數值＋第三量級（非負 size）** → 氣泡圖（面積映射，勿映半徑）；點重疊嚴重 → hexbin／contour
- **2 數值 + 時間只決定連線順序** → 連接散點
- **特徵 + log2 倍數變化 + p 值（原始／校正後）** → 火山圖（縱軸寫明哪種 p 值；有平均表現量 → 並列 MA 圖；有染色體位置 → 曼哈頓圖）
- **一批數量（或兩批數量，或一欄 p 值）+ 想比對的參考分布** → QQ 圖（常態 QQ／兩樣本 QQ／GWAS 風格 QQ／殘差 QQ；圖題寫清楚）
- **一批可排序數量 + 完全指定的參考 CDF（或兩批位置相近的數量）+ 想比累積機率** → P–P 圖（兩軸 0 到 1、對角線、等軸；圖題寫哪個軸放誰；繪點公式要寫；尾巴另並陳 QQ 圖）
- **同一批樣本的兩欄配對連續量測（method_a、method_b）+ 想看一致性與能否互換** → Bland–Altman 圖（橫軸平均、縱軸差值；先決定差值方向；扇形或傾斜時改百分比差異、取對數或迴歸式界限）
- **變異位點的染色體位置 + p 值（已有曼哈頓圖找出的區間）+ 想讀峰形、LD 與基因** → LocusZoom 圖（橫軸區間位置、縱軸 −log10(p)、依對領先變異的 r² 著色；圖註寫參考面板與族群）
- **染色體識別 + 長度或帶型座標（至少一種）+ 想標示的區間、拷貝數或密度** → 核型圖／染色體帶型示意圖（單條加標註、成對核型或全基因體橫向 ideogram；圖註寫基因體版本；沒有帶型也沒有著絲點的只有長度 → 長條圖）
- **多列研究 + 每列有效應量與信賴區間（或可由標準誤算出）+ 權重（精確度）** → 森林圖（比值類先取自然對數；有亞組可畫亞組菱形；列數約 5–40；隨機效應要寫明 τ² 估計法）；只有兩點沒有區間 → 啞鈴圖；一組原始資料的分布 → 箱形圖；兩種量測方法的一致性 → Bland–Altman 圖
- **很多條對齊時間軸的序列 + 一個基準 + 列高有限** → 地平線圖（先決定基準；帶數以 2 帶為主；鏡射或 offset 二選一寫在圖說；跨列比較共用帶寬）；組成疊加 → 河流圖；分布形狀 → 山脊圖
- **特徵 + 平均表現（baseMean／A）+ 對數倍數（M）（+ p 值／q 值著色）** → MA 圖（收縮前後可並陳；候選排序另畫火山圖）
- **標記 + 染色體 + 位置 + p 值** → 曼哈頓圖（依染色體、位置排序後累加當橫軸；兩性狀 → 邁阿密圖；同一欄 p 值另畫 QQ 圖）
- **類別 × 類別 + 值** → 矩陣熱圖（先檢查各欄尺度，必要時依欄／列正規化）／馬賽克（獨立性）；**外層區隔 + 內層組成 + 可加總量（欄寬＝規模）** → 馬里梅可
- **path／父子 + 數值** → 冰柱／旭日／treemap／圓堆／Voronoi 樹狀
- **已收合堆疊（`根;…;葉 計數`）／帶堆疊的取樣剖面** → 火焰圖（非組成；橫軸不是時間）；**帶時間戳的呼叫軌跡** → 火焰時序圖
- **起點 + 有符號增量串** → 瀑布
- **有序階段 + 通過量（單調不增）** → 漏斗
- **來源→去向 + 流量** → 桑基；階段重分組 → 沖積；方陣交換 → 弦圖
- **扇區（長度）＋ 區間軌道（位置＋值）＋ 兩端位置的連線表** → Circos
- **節點 + 邊** → 力導向／弧線／鄰接矩陣；+階層葉連線 → HEB；**節點 + 邊（稠密、多重邊或有邊類型／條件／時間欄）** → BioFabric
- **類別 + 連續數值（多組分布摘要）** → 箱形圖；要密度／雙峰 → 小提琴；雲＋雨＋傘 → 雨雲；每點 → 蜂群
- **每日一值** → 日曆熱力
- **長時間序列（數年以上）+ 穩定週期（12 月／52 週／7 天／24 小時）** → 螺旋圖（一圈＝一週期）；只看趨勢 → 折線
- **任務 + 開始 + 結束** → 甘特
- **實際 + 目標 + 質性區間** → 子彈
- **geo 區塊 + 比率** → choropleth；**geo 區塊 + 可數計數疏密** → 點密度圖（一對多）；**真實 lat/lon 落點** → 點密度／標記圖（一對一）；**點 + 總量規模（地圖）** → bubble map／比例符號；**笛卡兒 X／Y＋第三 size** → 氣泡圖（非地圖）；**起迄流向** → flow map

## 易混圖種（專案維護者整理口訣摘錄）

| 不要混 | 差在哪 |
|--------|--------|
| 冰柱 vs 旭日 | 同一套 partition；冰柱＝直角深度軸好標字；旭日＝環帶緊湊 |
| 冰柱／旭日 vs 桑基 | 隸屬組成 ≠ 有向流量 |
| Circos vs 弦圖 | 外圈＝長度刻度參考軸＋同心多軌＋位置對位連線 ≠ 外圈＝類別弧段（弧長≈總量）、只有流量弦；弦圖≈Circos 最內層連線層 |
| Circos vs 弧線圖 | 圓形刻度軸＋多層軌道 ≠ 直線版面、只講拓撲 |
| Circos vs 階層邊捆綁 | 外圈是位置刻度軸、重點多軌對齊 ≠ 外圈是階層葉節點、邊依階層捆束 |
| Circos vs 圓形長條 | 多軌＋連線＋位置座標 ≠ 單層類別長條（≈Circos 一條直方圖軌道） |
| Circos vs 旭日 | 同心環＝同一位置多層訊號 ≠ 同心環＝階層深度 |
| Circos（官方 Perl）vs circlize／pyCirclize | 官方軟體（GPL 第 3 版）≠ 同家族實作（MIT），圖注勿寫「用官方 Circos 做」 |
| 火焰圖 vs 火焰時序圖（Flame Chart） | 橫軸＝合併後樣本人口、依函式名字母排序、同函式不同時間併成一框 ≠ 橫軸＝時間順序、幾乎不合併（Chrome 開發者工具 Performance、speedscope Time Order） |
| 火焰圖 vs 冰柱圖 | 堆疊取樣的效能熱路徑（冰柱布局只是上下顛倒）≠ 任意階層加總的隸屬組成；判斷看資料與坐標軸，不看方向 |
| Plotly「flame chart」vs 火焰圖 | Plotly 指冰柱往上長的方向別名 ≠ 堆疊取樣火焰圖 |
| 火焰圖顏色 | 原版 CPU 隨機暖色無資料意義 ≠ Memory 綠、Differential 紅增藍減等刻意色票 |
| QQ 圖 vs P–P 圖 | 軸是分位數的實際數值（分位數對分位數）≠ 軸是 0 到 1 的累積機率（機率對機率），常被混淆；P–P 在分布中央較敏感、QQ 在尾部較敏感（GeostatsGuy、reliability、SAS 的定性說法，不是定理，維基百科 P–P 條目沒寫）；P–P 不保持位置與尺度，QQ 保持（SAS）；詳見 `examples/pp-plot.md` |
| P–P 圖：軸放誰 | 各來源不一致（多數橫軸理論、縱軸樣本；reliability 半參數相反）；statsmodels `ppplot` 軸標與實際放的內容相反；換軸曲線鏡射，「線上方」意思反過來——圖題一定要寫 |
| P–P 圖 vs NIST「Probability Plot」／SciPy `probplot` | 軸是 0 到 1 的累積機率 ≠ 軸是數值（有序觀測值對次序統計量中位數）；後兩者屬 QQ／機率圖，不是 P–P |
| P–P 圖的「P value plot」 vs 曼哈頓圖 | p 值分布對均勻分布的 P–P 結構（Davidson 與 MacKinnon 1998，對應屬推論）≠ 逐點畫成天際線的曼哈頓圖 |
| QQ 圖：貼 y = x vs 貼任意直線 | 貼 y = x 才表示分布相近 ≠ 貼任意直線只表示線性關係（位置、尺度可不同）；位置差＝平移、尺度差＝斜率、彎曲＝形狀不同 |
| QQ 圖 vs SciPy `probplot` | 官方文件明寫 probplot 畫的是機率圖，不要與 Q-Q 或 P-P 圖混淆（紅線是最小平方擬合線） |
| QQ 圖 vs 曼哈頓圖 | 期望對觀察 −log10(p)（整體有沒有偏）≠ 位置 × −log10(p)（在哪裡）；配套不互相取代 |
| 基因組膨脹係數 λ | qqman `qq()` 不計算 λ；λ 沒有單一官方閾值（1.05、1.10 兩種說法互相不一致）；偏高也可能是多基因遺傳的真實訊號 |
| MA 圖 vs 火山圖 | 橫軸 A 平均表現、縱軸 M 倍數，偏診斷 ≠ 橫軸倍數、縱軸 −log10 p，偏候選排序（有網站把火山圖軸寫反，勿抄） |
| MA 圖 vs RA 圖 | 軸語意相同（R 和 M 一樣放縱軸）；RA 圖只用於整數計數，用 ε 納入單邊為零的點 |
| MA 圖 vs Bland–Altman 圖 | 維基百科說 MA 圖是 Bland–Altman 圖應用於基因體資料、取對數後的版本；但用途與解讀門檻不同——MA 圖看豐度層級上的變化與正規化，Bland–Altman 圖看兩種量測方法的一致性，用原尺度的平均與差、常畫 ±1.96 SD；**不寫成同一種圖**（`examples/bland-altman.md`） |
| Bland–Altman：一致性界限 vs 信賴區間 | 界限描述差值的分布（差值近似常態時預期涵蓋約 95% 差值）≠ 信賴區間；平均差與兩條界限各有自己的信賴區間；能否互換看界限連同信賴區間是否在事先訂好的可接受範圍（臨床／專業判斷） |
| Bland–Altman：相關高 vs 一致 | 相關係數高不代表一致（可能整批偏高或差很多）；也不是「95% 的點必落在界限內」 |
| Bland–Altman：差值方向 | 各來源不同（A 減 B、B 減 A、新方法減標準）；圖題要寫，方向決定平均差正負號 |
| Bland–Altman 圖 vs Gardner–Altman 圖 | 配對量測的一致性 ≠ 兩個獨立組的平均差與信賴區間；名字相近，不是同一種（Gardner–Altman 尚無專檔） |
| `lfcShrink` 後的 MA 圖 | 預設不改 p 值，顯著點只是被拉向零（推論）；收縮是有意偏向零的估計 ≠ 真值 |
| 曼哈頓圖 vs QQ 圖 | 位置 × −log10(p)，回答「在哪裡」≠ 期望 × 觀察 −log10(p)，回答「整體是否膨脹」（配套，不互相取代） |
| 曼哈頓圖 vs LocusZoom 圖 | 全基因組天際線總覽 ≠ 單一區段＋r² 著色＋基因軌（找到尖塔後的下一步，`examples/locuszoom.md`） |
| LocusZoom：領先變異 vs 因果變異 | 領先（lead）變異是最顯著、著色基準的點，不等於因果變異；中文不要寫「鉛變體」（lead 誤譯） |
| LocusZoom：一叢高 LD 紅點 vs 獨立訊號 | 與單一關聯訊號一致，但不能證明只有一個因果變異；也不等於很多個獨立發現；低 LD 的高處第二個峰要做條件分析才能說獨立 |
| LocusZoom：LD 顏色 | 依參考面板與族群計算，不是資料自帶；換族群顏色會變；各工具顏色與右軸單位不同（cM/Mb 對 %；locuszoomr 疊 eQTL 時顏色是效應不是 LD） |
| LocusZoom 圖 vs 共定位／精細定位／條件分析 | 三件不同的事，LocusZoom 圖本身都不是 |
| karyogram vs ideogram | 英文維基百科把兩者當同義詞，都涵蓋顯微照片與示意圖；**不要**說成「karyogram＝照片、ideogram＝示意圖」；英文維基百科的 Ideogram 條目是文字意符，不是染色體圖，`Chromosome_ideogram` 頁面不存在 |
| 核型圖／帶型示意圖 vs 曼哈頓圖／LocusZoom／Circos | 前者畫染色體形態與帶型；曼哈頓圖與 LocusZoom 是位置 × −log10(p)，Circos 是環狀多軌；帶型條只能當導航或環的參考軸；詳見 `examples/karyotype-ideogram.md` |
| 核型圖：帶號方向與缺失框 | 帶號由著絲點往端粒遞增（p 臂頂端最外層最大）；缺失或重複的色框只框有變化的那一條；帶型表與標註座標要同一個基因體版本 |
| 森林圖 vs 漏斗圖（統合分析 Funnel plot）vs 漏斗圖（商業 Funnel chart） | 森林圖＝一列一項研究的估計與信賴區間加合併菱形；統合分析漏斗圖＝每點一項研究、橫軸效應量、縱軸精確度，檢查小研究是否偏向一側（至少約 10 項才做不對稱檢定，Cochrane 手冊第 13 章）；商業漏斗圖＝階段逐步留存／流失（`funnel-stages.md`）；三者名字相近、用途不同，不要混用、不要併檔 |
| 森林圖：軸與記號 | 比值（RR、OR、HR）先取自然對數、畫對數軸、無效線在 1；差值線性軸、無效線在 0（metafor 示範圖的對數風險比軸無效線在 0）；方塊面積∝權重（不是邊長；Excel 手動縮放邊長∝√權重屬推論）；菱形中心＝合併估計、寬度＝合併信賴區間；Bland–Altman 的 ±1.96 標準差描述個體差異範圍，森林圖的 ±1.96 標準誤描述估計的不確定性 |
| 森林圖：DL vs PM、I² 分級 | statsmodels `combine_effects` 預設是 Paule–Mandel（`method_re='iterated'`），DerSimonian–Laird 要設 `'dl'`，兩者 τ² 不同（範例 0.05965 對 0.03435），圖註寫明；I² 的粗略分級（Cochrane 第 10 章 0–40／30–60／50–90／75–100%）刻意重疊，範例 54.9% 同時落在兩個區間，不要硬分類 |
| 地平線圖 vs 小多折線／熱圖／河流圖／山脊圖 | 地平線＝一條序列一列、相對基準切帶疊回矮條、保留時間形狀；小多折線每條要夠高才讀得準；熱圖一格一色、常看不出沿時間的形狀；河流圖多條疊成一張、看總量與組成；山脊圖看形狀，地平線看相對基準的漲跌強度（`examples/horizon-chart.md`） |
| 地平線圖：基準、顏色、各自縮放 | 基準要寫在圖說（0、平均、目標、期初）；顏色以圖例為準（常見藍正紅負，Cubism 示範是綠正藍負）；深度＝層數＝幅度；各列各自縮放時跨列不可比，要比就共用帶寬；矮條高度不是真實振幅（2 帶＝折線全距的 1/4） |
| 地平線圖：函式庫預設與研究結論 | Cubism、d3-horizon 預設 offset；latticeExtra 預設鏡射；ggHoriPlot 鏡射要自己打開；kmandov 預設未找到——**不要寫「多數預設鏡射」**；Heer 等人 CHI 2009 只測兩點數值比較（18／30／8 位受試者），圖高低於約 24 像素 2 帶才比折線準，鏡射與 offset 無顯著差異，不建議 4 帶以上；「Saito 發明」是 Heer 論文的說法（Saito 全文未讀到）；「十幾條以上才划算」沒有出處 |
| 柏拉圖 vs 一般長條圖／瀑布圖／漏斗圖／洛倫茲曲線／ABC 分析 | 柏拉圖＝類別由大到小的直條＋累計百分比折線與右軸；一般長條圖不要求排序、沒有累計線；瀑布圖畫起點到終點的增減；漏斗圖順序是流程順序，不是依大小排；洛倫茲曲線與柏拉圖相通但不同（個體由小到大排、兩軸累計百分比、曲線凸向下；同一組數字，柏拉圖累計折線把順序倒過來、轉半圈就是洛倫茲曲線，柏拉圖第 k 點＝1−洛倫茲在 1−k／n 處；Juran 1975 自承手冊的累計曲線應歸給 Lorenz，pareto-chart.md 已核對原文）；ABC 分析是存貨分類管理方法（條目舉例 A 類＝20% 品項占 70% 年消耗價值，無固定門檻）；見 `examples/pareto-chart.md`、`examples/lorenz-curve.md` |
| 柏拉圖：「其他」位置、Excel 內建圖、左軸最大值 | 「其他」**通常**放最右（文字出處只有 Six Sigma Material，ASQ 不規定，不要寫「永遠」）；Excel 內建 Pareto 圖自動重排、固定不了「其他」，要固定請用組合圖；左軸最大值要設成總數，否則柱頂與累計線第一點對不上；右軸建議畫到 100% |
| 柏拉圖：80/20、起源、撞名 | 80/20 只是經驗法則（可能是 90:10 或 70:30），讀法是看累計線第一次到達或越過 80% 是第幾項；起源有據年份 1951，1941 只見英文維基百科與 Lean Enterprise Institute、與 Juran 自述不一致；「柏拉圖」同時是哲學家 Plato 的譯名，「Pareto 前沿」「帕累托最優」是不同概念；Google 試算表「沒有 Pareto」是從官方清單推論，官方未明文 |
| 管制圖 vs 折線圖／柏拉圖／直方圖／規格圖 | 管制圖＝折線圖＋由流程資料算出的中心線與管制界限＋判異規則，問「流程有沒有變」；折線圖只畫趨勢；柏拉圖是某段期間各類別的排名與累計占比（橫斷面快照）；直方圖不保留時間順序；規格線是顧客或圖面要求，不是管制界限；見 `examples/control-chart.md` |
| 管制圖：管制界限 vs 規格界限、受控 vs 合格 | 維基百科：兩者沒有內在關聯；NIST：管制界限判斷流程是否統計受控，規格界限判斷產品能不能照預期運作；流程可受控卻仍不符規格；「點全在規格內也可能已失控」是教學稿作者的推論；教學模擬圖的界限是預先設定、不是由資料算出 |
| 管制圖：判異規則的點數、3σ 與誤報 | 連續同側 Western Electric 8 點、Nelson 9 點，數點含起點，看資料前先約定；NIST 趨勢規則與 Nelson 都是連續 6 點遞增或遞減、14 點上下交替；只用單點超 3σ 約每 371 點誤報一次（維基百科 370.4），加 Western Electric 全部規則約每 91.75 點；3σ≈99.73% 只在近似常態且參數已知時成立；界限若只由少量資料算出誤報率可能差很多；改善後在新穩定態才重算界限（NIST 三種時機），不要太常改 |
| 洛倫茲曲線 vs 柏拉圖／折線圖／分位數圖 | 洛倫茲＝個體由小到大排、兩軸都是累計百分比、從 (0,0) 到 (100%,100%) 並附對角線，問「最貧 X% 合計占多少」；柏拉圖排類別、由大到小，折線凹向上，問「先處理哪幾類」，同一組數字的柏拉圖折線轉半圈就是洛倫茲曲線（相通但不同，不是同一種圖）；折線圖橫軸是時間，洛倫茲橫軸是排序後的名次比例，不是趨勢線；分位數圖縱軸是原始數值（門檻值），洛倫茲縱軸是份額；見 `examples/lorenz-curve.md` |
| 洛倫茲曲線：基尼係數要註明算法 | 折線下面積法 G＝1−2B 與乘 n／(n−1) 的小樣本修正，10 戶差約 11%（虛構 S3：0.382→0.424）；一人全拿未修正是 (n−1)／n（10 戶 0.90、100 戶 0.99），修正後才是 1，所以「趨近 1」寫成「戶數越多越趨近 1」；負值（債務）可使曲線起點低於零、基尼超過 1；口徑（稅前後、個人／家戶、年份）不同不能同圖比；見 `examples/lorenz-curve.md` |

## 編碼規則（短）

- 數量：位置 > 長度 > 角度 > 面積 > 色相。
- 一個主問題一個主編碼。
- 雙軸：僅在使用者堅持時；兩軸都標清楚；寧可指數化／雙面板。
- 堆疊絕對值：看總量+粗組成可以；比中段 → 分組長條或 100% 堆疊 + 旁表。
- 圓／面積編碼：旁邊準備表格或改長條給要精準比的人。

# 資料形狀檢查

推薦圖表前先跑這些檢查。輸出短診斷，不要寫論文。

## 欄位角色

每個欄位指定一個主角色：

| 角色 | 訊號 |
|------|------|
| time | date, datetime, year, month, 期別, 年月 |
| category | 名稱, id, 部門, 產品, region（無序） |
| ordered-category | 評等, 年齡層, Likert, 階段, 漏斗階 |
| numeric | 金額, 數量, %, 指數 |
| hierarchy | parent/child, path, 科目樹, org levels |
| geo | 縣市, 郵遞區號, lat/lon, ISO 區碼 |
| network-node / edge | 來源, 去向, 權重, 共現 |
| id | 不透明鍵（通常不單獨畫） |

## 結構探測

1. **粒度**：一列＝？（日／人／訂單／科目／邊…）。不清就先問或標「假設」。
2. **基數**：類別 distinct 數。>12–15 比大小 → top-N＋其他、改表、或小多圖／圓形長條（搶眼用）。
3. **缺值／零**：0 是真實還是空白；地理缺值不要 silently 變零面積。
4. **單位**：混用千元／元／%？統一再畫。
5. **重複鍵**：同 key 多列 → 聚合規則（sum/mean/last）。
6. **極端值**：是否 log、截尾、或獨立標註。
7. **寬 vs 長**：寬表常需 melt 成長表再畫折線／長條。
8. **階層閉合**：子加總是否＝父；不相等先清。
9. **流量方向**：有向／無向；漏斗是否單調不增。
10. **網路面貌**：邊數、是否毛球、有無可信階層可做 HEB。
11. **非負組成隨時間**：類別數是否可控；度量是否全非負；要流動感（河流圖）還是貼零讀總量（堆疊面積）還是單層精準（折線）。
12. **年齡×雙側**：年齡組是否可排序、間距是否一致；左右是否同單位；要比輪廓還是精讀差額。
13. **類別+單值 vs 雙值**：一值→長條／棒棒糖；兩同單位值→啞鈴；勿把雙點互連叫棒棒糖。
14. **分布摘要 vs 密度 vs 每點**：多組要比中位／IQR／離群 → 箱形；要雙峰／外形 → 小提琴／雨雲；要個體點 → 蜂群；勿把單一彙總值硬畫成箱。
15. **兩數值＋第三量級 vs 地圖氣泡**：x＋y＋非負 size（笛卡兒）→ 氣泡圖（面積映射）；圓心在 lat/lon／行政區 → bubble map／比例符號；只要兩變數 → 散點；第三維要精準排名 → 長條／棒棒糖。
16. **區隔×組成（馬里梅可）**：外層類別數約 3–8、內層約 3–7；度量可加總且非負；欄寬占比加總≈100%；百分比軸下每欄內部占比加總＝100%；類別過多先併「其他」。要獨立性檢定 → 馬賽克，不是 Mekko。
17. **地理區塊填色（等值區域）**：指標是否已正規化——若只有總量，分母欄（人口、面積、戶數）是否存在且非零？沒有分母就別填色，改比例符號地圖；區域代碼能否對上邊界檔（同編碼、同年份），join 後列出未匹配區；缺值區標「無資料」（灰／斜線），不當 0；分級方法（分位數／等距／自然斷點）與色階（順序／發散）要能說明。

## 問題類型 → 下一步

| 問題 | 去哪 |
|------|------|
| 誰大誰小 | chart-heuristics → 長條／棒棒糖／表 |
| 兩期差多少 | 啞鈴／坡度 |
| 年齡結構輪廓（雙側） | 人口金字塔 |
| 怎麼變 | 折線／河流圖（組成河）／凹凸；貼零總量用堆疊面積 |
| 是否相關／密度 | 散點／氣泡圖（＋第三量級）／hexbin／等高線／熱力 |
| 佔多少／階層 | 堆疊／華夫／冰柱／旭日／treemap／圓堆；區隔規模＋區內組成 → 馬里梅可 |
| 從 A 怎麼變成 B | 瀑布 |
| 哪一階漏掉 | 漏斗 |
| 流去哪 | 桑基／沖積／弦圖 |
| 交叉表獨立性 vs 市場地圖 | 馬賽克（列聯／殘差）／馬里梅可（變寬堆疊） |
| 誰連誰 | 力導向／弧線／鄰接矩陣／HEB |
| 分布長怎樣 | 箱形／小提琴／蜂群／雨雲／山脊 |
| 地圖上哪裡大／哪裡密 | choropleth（比率，先正規化）／點密度圖／bubble map（≠笛卡兒氣泡）／cartogram／flow map |
| 很多同類比較 | 小多圖 |

## 最小可用樣本

偏好：表頭 + ≥5–20 列 + 單位說明。只有截圖 → 先推薦並請機器可讀摘錄。

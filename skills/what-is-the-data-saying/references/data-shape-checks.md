# 資料形狀檢查

推薦圖表前先跑這些檢查。輸出短診斷，不要寫論文。

## 欄位角色

每個欄位指定一個主角色：

| 角色 | 訊號 |
|------|------|
| time | date, datetime, year, month, 期別, 年月 |
| category | 名稱, id, 部門, 產品, region（無序） |
| ordered-category | 評等, 年齡層, Likert, 階段, 漏斗階 |
| numeric | 金額, 數量, %, 指數 |
| hierarchy | parent/child, path, 科目樹, org levels |
| geo | 縣市, 郵遞區號, lat/lon, ISO 區碼 |
| network-node / edge | 來源, 去向, 權重, 共現 |
| id | 不透明鍵（通常不單獨畫） |

## 結構探測

1. **粒度**：一列＝？（日／人／訂單／科目／邊…）。不清就先問或標「假設」。
2. **基數**：類別 distinct 數。>12–15 比大小 → top-N＋其他、改表、或小多圖／圓形長條（搶眼用）。
3. **缺值／零**：0 是真實還是空白；地理缺值不要 silently 變零面積。
4. **單位**：混用千元／元／%？統一再畫。
5. **重複鍵**：同 key 多列 → 聚合規則（sum/mean/last）。
6. **極端值**：是否 log、截尾、或獨立標註。
7. **寬 vs 長**：寬表常需 melt 成長表再畫折線／長條。
8. **階層閉合**：子加總是否＝父；不相等先清。
9. **流量方向**：有向／無向；漏斗是否單調不增。
10. **網路面貌**：邊數、是否毛球、有無可信階層可做 HEB。
11. **非負組成隨時間**：類別數是否可控；度量是否全非負；要流動感（河流圖）還是貼零讀總量（堆疊面積）還是單層精準（折線）。
12. **年齡×雙側**：年齡組是否可排序、間距是否一致；左右是否同單位；要比輪廓還是精讀差額。
13. **類別+單值 vs 雙值**：一值→長條／棒棒糖；兩同單位值→啞鈴；勿把雙點互連叫棒棒糖。
14. **分布摘要 vs 密度 vs 每點**：多組要比中位／IQR／離群 → 箱形；要雙峰／外形 → 小提琴／雨雲；要個體點 → 蜂群；勿把單一彙總值硬畫成箱。
15. **兩數值＋第三量級 vs 地圖氣泡**：x＋y＋非負 size（笛卡兒）→ 氣泡圖（面積映射）；圓心在 lat/lon／行政區 → bubble map／比例符號；只要兩變數 → 散點；第三維要精準排名 → 長條／棒棒糖。
16. **區隔×組成（馬里梅可）**：外層類別數約 3–8、內層約 3–7；度量可加總且非負；欄寬占比加總≈100%；百分比軸下每欄內部占比加總＝100%；類別過多先併「其他」。要獨立性檢定 → 馬賽克，不是 Mekko。
18. **圖塊地圖（一區一格）**：每區恰一列、恰一格；格座標 (row, col) 不重複；區域代碼完整（對照表或底圖每區都有對應，缺值標「無資料」不當 0）；指標已正規化。若是加權變體（格數＝人口／選舉人票），各區格數加總要等於總數，圖例寫「1 格＝N」，並改歸統計變形地圖。
17. **地理區塊填色（等值區域）**：指標是否已正規化——若只有總量，分母欄（人口、面積、戶數）是否存在且非零？沒有分母就別填色，改比例符號地圖；區域代碼能否對上邊界檔（同編碼、同年份），join 後列出未匹配區；缺值區標「無資料」（灰／斜線），不當 0；分級方法（分位數／等距／自然斷點）與色階（順序／發散）要能說明。
19. **列 × 欄數值矩陣（矩陣熱圖）**：能否樞紐成「列 × 欄 → 一個值」（長格式 row, col, value 或寬表）？同一組合重複列先定聚合規則；各欄尺度差很大時先依欄或依列正規化，不然大數值欄主導顏色；缺值用獨立樣式、不當 0；有中點（相關係數 −1～+1）→ 發散色階，單向高低 → 循序；列欄有固定順序就保持，要看相似才分群重排；列欄極多先篩選或分群。兩軸是同一組網路節點、格子是邊 → 鄰接矩陣；每日一值排日曆版面 → 日曆熱力圖。
20. **長序列＋週期（螺旋圖）**：時間戳記連續、排序正確、無重複；跨度數年以上；週期長度穩定（12 個月、52 週、7 天、24 小時），每圈點數一致（例如每年都有 12 個月）；缺值處理寫明；需要時先彙總到與週期對齊的顆粒度（日 → 週／月）；氣候異常要有基準期與單位。週期不穩或只看趨勢 → 折線。
21. **稠密網路邊表（BioFabric）**：至少 `source, target`；有向或無向要講清楚、有向保留方向；邊的端點都在節點清單內；多重邊／平行邊保留為獨立列（本圖每邊一欄）；關係類型、條件、時間、權重另開欄位供分組；節點分區欄（例如部門）可排列序。節點少、邊稀疏 → 力導向／弧線；只要有無矩陣 → 鄰接矩陣；邊權重要精確比較 → 附表。
22. **堆疊取樣剖面（火焰圖）**：資料是否真的帶呼叫堆疊（取樣剖面或已收合堆疊 `根;…;葉 計數`）？只有扁平計數 → 長條／表，不要假造堆疊；每行最後一欄是非負整數樣本數、路徑以 `;` 分隔；同路徑重複行要加總；框名是否大量 `[unknown]`／塔過矮（符號、除錯資訊不全）；取樣條件（剖析器、頻率、時長、時段）有沒有；週期或突發時段是否混在一起。有時間戳、要順序 → 火焰時序圖；一般 parent–child 組成表 → 冰柱，不是火焰圖。
23. **環狀多軌（Circos）**：有沒有「帶長度刻度的參考軸」？沒有位置座標、只有類別流量 → 弦圖／桑基。扇區表 id 唯一、長度與單位一致、順序明確；軌道表的扇區 id 都在扇區表內、起訖位置落在扇區長度範圍內、各軌道位置單位相同（同一角度才能對齊）；連線表兩端扇區存在、位置在範圍內、方向欄與起訖大小一致（起點大於終點＝反向）；連線太多先依長度／強度篩選並設透明度。
24. **差異分析結果（火山圖）**：每列一個特徵、特徵名唯一；有效應量（log2 倍數變化，正負方向對應哪個對比要寫明）與 p 值；確認縱軸用原始或校正後 p 值（校正法如 Benjamini–Hochberg 寫明），p 值在 0 到 1 之間、為 0 時 −log10 會無限大要先處理；門檻在分析前定好（範例，不是標準）；只有原始計數矩陣、還沒做檢定 → 先做差異分析；橫軸其實是染色體位置 → 曼哈頓圖；有平均表現量 → 可並列 MA 圖。
25. **全基因組關聯摘要（曼哈頓圖）**：每列一個標記、編號唯一；有染色體（從 1 起算，X／Y 等非數字染色體要定好順序）與染色體內位置（同一參考基因組版本、同一單位）；p 值在 0 到 1 之間、為 0 時 −log10 會無限大要先處理；依染色體、位置排序後累加當橫軸；門檻事先約定（範例，不是標準）；只有任意兩欄數字、沒有染色體與位置 → 不是曼哈頓圖；只有少數候選位點 → 表格或點圖；同一欄 p 值另畫 QQ 圖檢查膨脹。
26. **兩條件差異結果（MA 圖）**：每列一個特徵、編號唯一；有 A（`baseMean`、平均正規化計數或平均對數強度，說明是否對數刻度）與 M（`log2FoldChange`，底數要一致；小心教學用 `log1p` 卻稱 log2）；要著色顯著點另需 p 值或校正後 q 值，並寫明是檢定結果還是單純 |M| 門檻；未收縮與收縮後的結果表分開存、圖說標明；計數資料要有正的平均計數，單邊為零的點怎麼處理（過濾、edgeR 抹開、RA 圖 ε）要寫明；只有 p 值沒有表現量或倍數 → 畫不了；橫軸其實是位置 → 曼哈頓圖；要候選排序 → 火山圖。
27. **分位數對分位數（QQ 圖）**：至少一組可排序的數量值（或一欄 p 值）；理論 QQ 要先選參考分布（常態最常見）；兩樣本 QQ 要兩組數量（筆數不必相同，各取相同累積比例比較）；p 值要在 0 到 1 之間、不含 0（−log10 會無限大）；點太少（十個以下）要保守；殘差 QQ 要確認餵進去的是模型殘差並在圖題寫「殘差」；沒有可排序數量、只有類別 → 資料前提不夠；想比對累積機率曲線 → P–P 圖；軸怎麼擺（理論在橫軸或縱軸）要寫在軸標題。
28. **兩種量測方法的一致性（Bland–Altman 圖）**：要有**配對**的兩欄連續量測（同一批樣本或受試者、一列一對，至少 method_a、method_b），沒有配對或只有單一方法 → 資料前提不夠；只有類別結果 → 不適用；先寫下**差值方向**（A 減 B 或 B 減 A，圖題、圖說、正文一致）；檢查的是**差值**（不是兩方法量測值本身）是否近似常態、散布是否隨平均值變大（扇形）、走勢是否隨平均值傾斜（比例性偏差）；平均值接近 0 時百分比差異不穩定；每人每法有重複量測時不能直接套經典公式；樣本太少時界限的信賴區間很寬（Bland 個人建議約 100 位，不是公認門檻）；要先有事先訂好的可接受範圍（臨床／專業判斷）才能談能否互換；兩個獨立組的平均差與信賴區間 → Gardner–Altman 圖，不是本圖。
29. **區域關聯圖（LocusZoom 圖）**：每個變異位點至少有染色體、位置（同一參考基因組版本與單位）與 p 值（或可換算的檢定統計量；p 為 0 時 −log10 會無限大要先處理）；位置落在**同一段染色體區間**（跨多條染色體 → 曼哈頓圖）；要先決定領先（lead）變異怎麼選並寫進圖題（不寫「鉛變體」）；要上 LD 著色就要有對領先變異的 r²（或可查詢的參考基因型面板），並寫明參考面板與族群，沒有 LD 資料的點會是灰色；要畫基因軌需要基因註解來源與同一基因組組建；沒有座標或沒有關聯統計量 → 資料前提不夠；只想比任意兩欄 → 散點圖；縱軸若是效應量 beta 要在軸標題寫清楚；若想確認第二個峰是否獨立 → 需要條件分析的結果，不是這張圖能回答。

## 問題類型 → 下一步

| 問題 | 去哪 |
|------|------|
| 誰大誰小 | chart-heuristics → 長條／棒棒糖／表 |
| 兩期差多少 | 啞鈴／坡度 |
| 年齡結構輪廓（雙側） | 人口金字塔 |
| 怎麼變 | 折線／河流圖（組成河）／凹凸；貼零總量用堆疊面積；長序列要看季節對齊 → 螺旋圖 |
| 是否相關／密度 | 散點／氣泡圖（＋第三量級）／hexbin／等高線／矩陣熱圖（相關矩陣） |
| 列 × 欄哪裡熱／冷 | 矩陣熱圖（標註或分群）；日曆版面 → 日曆熱力圖；節點 × 節點 → 鄰接矩陣 |
| 佔多少／階層 | 堆疊／華夫／冰柱／旭日／treemap／圓堆；區隔規模＋區內組成 → 馬里梅可 |
| 程式時間耗在哪條呼叫路徑 | 火焰圖（堆疊取樣）；要時間順序 → 火焰時序圖；CPU 不忙但延遲高 → Off-CPU 火焰圖 |
| 從 A 怎麼變成 B | 瀑布 |
| 哪一階漏掉 | 漏斗 |
| 流去哪 | 桑基／沖積／弦圖 |
| 長參考軸上多層訊號＋區段對應 | Circos（沒有位置刻度 → 弦圖） |
| 分布形狀像不像某個參考分布／兩批像不像 | QQ 圖（累積機率曲線 → P–P 圖；GWAS 整體偏離 → QQ 圖並陳曼哈頓圖） |
| 兩種量測方法的一致性（同一批樣本的配對連續量測） | Bland–Altman 圖（寫差值方向；界限不是信賴區間；扇形或傾斜時改百分比差異、取對數或迴歸式界限；兩個獨立組 → Gardner–Altman 圖，尚無專檔） |
| 曼哈頓圖找到尖塔後的區間細節（位置＋p 值＋對領先變異的 LD＋基因） | LocusZoom 圖（領先變異與 LD 參考面板要寫；第二個峰要條件分析；不是因果證明） |
| 在什麼豐度層級上變、正規化或收縮是否異常 | MA 圖（候選排序 → 火山圖；整數計數含零 → RA 圖分界） |
| 全基因組關聯訊號落在哪裡 | 曼哈頓圖（兩性狀 → 邁阿密圖；整體膨脹 → QQ 圖；單一峰值 → LocusZoom 圖） |
| 大量特徵的差異結果哪些最值得追 | 火山圖（橫軸位置 → 曼哈頓圖；表現量層級偏差 → MA 圖） |
| 交叉表獨立性 vs 市場地圖 | 馬賽克（列聯／殘差）／馬里梅可（變寬堆疊） |
| 誰連誰 | 力導向／弧線／鄰接矩陣／HEB；稠密毛球、邊要可辨識或分組 → BioFabric |
| 分布長怎樣 | 箱形／小提琴／蜂群／雨雲／山脊 |
| 地圖上哪裡大／哪裡密 | choropleth（比率，先正規化）／圖塊地圖（每區等權重）／點密度圖／bubble map（≠笛卡兒氣泡）／cartogram／flow map |
| 很多同類比較 | 小多圖 |

## 最小可用樣本

偏好：表頭 + ≥5–20 列 + 單位說明。只有截圖 → 先推薦並請機器可讀摘錄。

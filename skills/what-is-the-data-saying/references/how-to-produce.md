# 怎麼產出圖表（納茲教圖風格）

對齊納茲教圖習慣：**先故事句 → 適不適合 → 口述步驟 → 工具路徑 → 自檢**。
面向台灣繁體中文讀者；步驟可口述，程式碼只在使用者要落地實作時再給。

## 每次產出的固定骨架

1. **故事句**（一句）：這張圖要讓讀者看出什麼？
2. **資料契約**：需要哪些欄、型別、單位、加總規則。
3. **口述步驟**（5～8 步）：整理表 → 選編碼 → 排序／分色 → 標註 → 自檢。
4. **工具路徑**：無碼／Python／JS 各給最短路徑；沒有原生圖種要誠實說。
5. **自檢**：讀者能否回答故事句？會不會跟易混圖種搞錯？

## 共通產出規則

- 標題：`主結論或主題 — 時間範圍`
- 圖脚：`資料來源：…；單位：…；備註：…`
- 數字未核實寫「未核」；不要發明連結或案例數字
- 軸與圖例 zh-TW；變數名可 EN
- 靜態簡報：少系列、大字；互動：hover 細節、下鑽
- 避免：3D、無說明雙 Y 軸、彩虹無序類別色、把面積當精確比較卻不給表

## 依任務的口述要點（摘要）

完整 pattern 與 checklist 在 `examples/`。此處只留最短「動手順序」。

### 比較／差距

- **長條**：聚合 → 排序（除非固有序）→ 水平長標籤 → 標單位。
- **棒棒糖圖**：類別 + 單值 → 定基線語意（0／目標／平均）→ 無固有序就依數值排序 → 細莖+末端點（長標籤用水平）→ 少數強調色其餘灰；勿自稱 Datawrapper 原生 Lollipop（近路 Dot Plot；雙端＝Range／啞鈴）。
- **啞鈴**：類別 + 兩個同單位數值 → 兩點+連線 → 按差距排序 → 兩端分色圖例寫死。
- **坡度圖**：確認只要兩期 → 左右同尺 → 線=實體 → 升／降分色可選 → 標註誰升最快。
- **子彈圖**：實際棒 + 目標垂線 + 2～5 段質性底色（同色相深淺）→ 多指標對齊軸。

### 趨勢／排名／組成隨時間

- **折線**：長表 time+value(+series) → 少系列單圖，多系列小多圖。
- **凹凸圖**：每期內排名 → Y 軸名次反向（1 在上）→ 線交叉=超車。
- **河流圖（溪流圖／ThemeRiver）**：time+category+非負量（長或寬表）→ 先貼零堆疊面積對照 → 再切 stream／中軸／wiggle → 類別少、色差夠 → 互動補數值；不強求讀 Y 刻度；負值勿硬套。

### 分布

- **箱形圖**：類別+數值 → 箱＝IQR、中線＝中位數、鬚規則寫清（常 1.5×IQR）、點＝離群；可選平均菱形（≠ 中位）；標各組 n=；並排比多組摘要。Datawrapper **無**原生箱形；要密度／雙峰改小提琴／雨雲；要每點改蜂群。
- **蜂群**：數值軸=真值，另一軸只為避撞 → 保留點身份。
- **小提琴**：類別+數值 → 鏡射密度 + 建議內嵌盒／中位 → 標 n=。
- **雨雲**：半小提琴 + 原始點 + 箱／摘要三件疊加。
- **山脊**：多組密度上下錯位微疊 → 看眾數漂移／雙峰。

### 相關／密度

- **散點**：兩數值；可加趨勢／分組色。
- **氣泡圖**：entity＋x＋y＋size（非負）→ **面積**映射第三量級（勿映半徑／直徑）→ size 圖例必備 → 半透明防重疊 → 只標少數離群；Datawrapper＝Scatter 綁 size（無獨立 Bubble）；第三維要精準排名改長條／棒棒糖；地理分布改 bubble map。
- **矩陣熱圖（heatmap）**：樞紐成列 × 欄 → 一個值 → 各欄尺度差大就依欄／列正規化（圖注寫明）→ 循序色階（單向）或發散色階（有中點，如相關係數 0）；Viridis 類或 ColorBrewer，不用彩虹 → 缺值獨立樣式＋圖例 → 固定順序軸保持原序，要看相似才分群重排（clustermap＋樹狀圖）→ 格子少格內標數字、格子多靠圖例＋懸停。工具：R（ggplot2 `geom_tile`、lattice `levelplot`、基本 `heatmap()`）；Python（Seaborn `heatmap`／`clustermap`、Plotly）；D3 Graph Gallery；Flourish Heatmaps；Highcharts。Datawrapper 本輪查無熱圖專頁，不宣稱原生。日曆版面 → 日曆熱力；節點 × 節點 → 鄰接矩陣。
- **六角分箱／等高線**：點夠多且重疊才用；交代 bin／帶寬；對參數敏感要誠實講。
- **連接散點（型 B）**：X、Y 都是量測，時間只決定連線順序；找 loop／滯後。
- **火山圖（volcano plot；差異分析）**：確認故事是「大量特徵差異結果的優先排序」（任意兩欄 → 散點；橫軸位置 → 曼哈頓圖）→ 表：特徵＋log2 倍數變化＋原始／校正後 p 值，對比方向寫進圖說 → 縱軸 −log10 p，軸標題寫明原始或校正後 → 分析前定倍數與顯著性門檻（範例，不是標準；如 q < 0.05 且 |log2FC| ≥ 1、padj < 0.05 且 0.58），畫水平／垂直虛線 → 三色或四色著色、圖例寫門檻 → 只標要討論的特徵、加引線 → 檢查「倍數大但不顯著」「很顯著但倍數近 0」→ 必要時並列 MA 圖。工具：EnhancedVolcano（Bioconductor，GPL 第 3 版，預設四色；手冊預設 pCutoff 1e-05、FCcutoff 1）；ggplot2＋ggrepel；上游 DESeq2（`lfcThreshold`）、apeglm 收縮；Plotly Python（Dash Bio VolcanoPlot；R 語言版專頁不存在）；Galaxy；Seaborn、Matplotlib 無專屬範例、用散點組裝。
- **曼哈頓圖（Manhattan plot；全基因組關聯）**：確認故事是「關聯訊號落在基因組哪裡、多強」（橫軸效應量 → 火山圖；整體膨脹 → QQ 圖；單一峰值 → 區域放大圖）→ 表：標記編號、染色體、位置、p 值；性狀定義、樣本、多重檢定策略寫進圖說 → 縱軸 −log10(p)（用校正後 p 或 q 值要寫明）→ 事先約定門檻並畫線標數值（範例，不是標準；如 5×10⁻⁸≈7.30、提示性 1×10⁻⁵＝5 為工具預設）→ 染色體從 1 起算、依位置排序累加、相鄰交替色、軸標題寫人話 → 只標要討論的峰值 → 線性／環狀／互動；兩性狀用邁阿密圖（上下鏡像）→ 同頁並陳 QQ 圖 → 鎖定尖塔再畫區域放大圖（LocusZoom）。工具：qqman（R，GPL-3）；CMplot（R，GPL (≥ 2)，線性／環狀／多性狀）；Dash Bio `ManhattanPlot`（Python，MIT）；Matplotlib、ggplot2 手工拼；miami_generator（邁阿密圖）。manhattanly（MIT）已於 2025-06-13 自 CRAN 下架，不當目前推薦。
- **MA 圖（MA plot；平均－差值圖，診斷）**：確認故事是「在什麼豐度層級上變、正規化或收縮是否異常」（候選排序 → 火山圖；橫軸位置 → 曼哈頓圖）→ 表：特徵＋A（平均表現／`baseMean`）＋M（`log2FoldChange`）；要著色再加 p 值或 q 值 → 橫軸 A（多用對數刻度）、縱軸 M（底數一致）、畫 M＝0 線 → 顏色意義寫進圖例（檢定結果 vs 單純 |M| 門檻；門檻為範例，不是標準，如 padj < 0.1〔DESeq2 預設〕、padj < 0.05 且 |LFC| > 1）→ 未收縮與 `lfcShrink` 收縮後並陳（預設不改 p 值，顯著點只是被拉向零，此為推論；收縮是偏向零的估計，不是真值）→ 讀圖：是否以 M＝0 為中心（「多數基因沒差異」是假設）→ 低 A 區喇叭口 → 顯著點落在哪段豐度。RA 圖＝整數計數版，R 同樣放縱軸，用 ε 納入單邊為零的點；Bland–Altman 用原尺度、尚無專檔。工具：DESeq2 `plotMA`／`lfcShrink`（apeglm、normal、ashr）；limma／edgeR `plotMD`；Glimma 互動；ggplot2、Matplotlib 手作。

### 階層組成

- **共同**：葉非負值；父=子加總；層順序=深度／圈順序。
- **冰柱**：直角 partition，好標字、深層較不易被徑向擠壓；Flourish 常無原生冰柱。≠ 火焰圖（堆疊取樣）。
- **火焰圖（flame graph；效能剖面，非組成）**：確認故事是熱路徑不是時間順序 → 取帶堆疊的剖面（Linux perf／eBPF、DTrace、產品化剖析器、語言取樣器；符號齊備）→ 收合成 `根;…;葉 計數` → 標準（根在下）或冰柱布局（根在上）→ 色票寫明（CPU 隨機暖色無資料意義；Memory 綠；Differential 紅增藍減）→ 互動：懸停、點選放大、搜尋累計 → 有週期／突發先用 FlameScope 挑時段 → 讀法：最寬頂緣葉框 → 祖先 → 搜尋累加 → 對帳計數表；圖注寫「橫向不是時間」與取樣條件。要時間順序 → 火焰時序圖（Chrome 開發者工具 Performance、speedscope Time Order）。工具：`brendangregg/FlameGraph`（互動 SVG）、`d3-flame-graph`、speedscope、FlameScope。
- **旭日**：同一套 partition 改環帶；小塊靠 hover／下鑽。
- **矩形樹狀**：嵌套矩形鋪滿；葉面積∝值。
- **圓堆**：嵌套圓；面積弱於長度，精準比請旁表。
- **Voronoi 樹狀**：凸多邊形鋪滿；圖注寫「不是地圖」。

### 流動／階段

- **瀑布**：起點 + 有符號增量 + 終點；落地柱 vs 浮空柱；connector；正負分色。
- **漏斗**：有序階段 + 通過量；後階不大於前階；標轉換率與瓶頸。
- **桑基**：來源、去向、非負流量；帶寬=流量；弱邊可裁。
- **沖積**：2～5 有序階段重分組；塊=當階大小，帶=過渡量。
- **弦圖**：方陣或來源/去向/值；圓上節點+帶；裁弱邊、靠 hover。
- **Circos（環狀多軌圖）**：確認故事是「長參考軸＋多層訊號＋對位」（只有類別流量 → 弦圖）→ 扇區表（清單、長度、順序、方向）→ 軌道表（扇區＋起訖位置＋值／類別，同角度對齊）→ 連線表（兩端位置、方向、類型、寬度；先篩弱／短連線、調透明度）→ 由外而內：染色體示意圖 → 軌道 → 連線；執行期規則上色（不改原資料）→ 稀疏熱點局部放大／軸斷點 → 輸出 PNG／SVG，向量圖再微調標籤圖例；圖旁三句讀法。工具：官方 Circos（Perl 命令列、純文字設定檔；GPL 第 3 版）；R circlize、Python pyCirclize（MIT；同家族實作，不是官方版，圖注要寫明）。

### 類別交叉／集合／市場區隔組成

- **馬賽克**：交叉表；欄寬=邊際、格高=條件、面積=聯合；主線＝列聯／獨立性（殘差著色可選）。勿與商用 Marimekko 混稱。
- **馬里梅可／Mekko**：外層區隔 + 內層組成 + 可加總量 → 選百分比軸或絕對值軸 → 欄寬＝區隔總量占比、色帶高＝區內占比（或絕對堆疊）→ 外／內排序統一、細項併「其他」→ 大色塊直標、細帶圖例／hover；Flourish／think-cell／Qlik／Domo／Mekko Graphics 有原生；**Datawrapper 無原生**；Excel 常靠堆疊面積＋累積寬度。
- **平行集合**：多類別軸 + 頻率帶；可拖軸。
- **UpSet**：多集合交集；集合多時勝過 Venn。

### 網路

- **力導向**：節點+邊；先過濾規模；位置≠地理；標樞紐即可。
- **弧線**：節點排一條線（順序最關鍵）+ 弧=邊。
- **鄰接矩陣**：同一批節點×節點；**排序**後看團。
- **蜂巢圖**：放射軸分區規則要講得出；用來比較多張網。
- **HEB**：階層樹 + 葉↔葉連線；沿共同祖先捆線；缺一邊就不要畫。
- **BioFabric（生物織布圖，暫譯）**：確認故事是梳毛球／看邊與連線型態（不是流量寬度）→ 邊表 source／target（有向保留方向；類型、條件、時間、權重另欄；官方工具常用定位字元分隔／`.sif` 風格匯入）→ 定列序（度數、名稱或連通性相似）→ 定欄序（先來源列再目標列，讓邊扇成楔形；有連結分組先按組分塊）→ 每節點一條水平線、每邊一條垂直線段、端點標記 → 太寬用陰影連結、節點區底色、子集視圖／巡覽 → 圖例寫「列＝實體、垂直線＝關係」＋分組／方向 → 精確數字另附計數表。工具：BioFabric Java 桌面版（`wjrl/BioFabric`，LGPL 2.1）、RBioFabric（`wjrl/RBioFabric`，未上架 CRAN，從 GitHub 裝）、D3BioFabric（`wjrl/D3BioFabric`）、yFiles（產品說明頁）。

### 地理／時間骨架／剖面

- **日曆熱力**：聚合到每日一值；週×星期；寫週起始與時區。
- **螺旋圖（spiral plot）**：確認需要「週期對齊＋長序列」（只看趨勢用折線）→ 定一圈＝一個週期與方向（中心較早、外圈較新），寫在圖上 → 排序、缺值、必要時彙總到週期顆粒度 → 軌道編碼：長條／棒棒糖（振幅高峰）、折線／面積（連續起伏）、螺旋熱圖色塊（分級強度）、地平線（進階）→ 外圈角度刻度＋數值圖例（單位；氣候異常寫基準期）→ 圈太密就縮年份、拉大圈距或做動畫 → 提醒外圈弧長較長，精確差值另附對照表或線性局部圖。工具：R `spiralize`；D3 社群實作（tomshanley d3-spiral-heatmap、Condegram gist）；氣候螺旋範本 Ed Hawkins Climate Visuals、NASA SVS 5190。data-to-viz／Flourish／R・Python Graph Gallery 無專頁。
- **甘特**：任務+開始+結束；少畫依賴箭頭。
- **雷達**：軸必須可比、同尺；系列少；面積≠總分。
- **平行座標**：多連續軸；先縮放；軸順序影響可讀性。
- **等值區域圖（choropleth）**：區域代碼＋已正規化指標（分子／分母→比率、每十萬人、每面積）→ 對上邊界檔（同編碼、同年份，檢查未匹配）→ 連續或分級（寫明分位數／等距／自然斷點）→ 順序或發散色（中心值寫明；ColorBrewer）→ 缺值灰／斜線＋「無資料」→ 只標要點名的區；總量改比例符號地圖；大面積低人口偏誤要註明或並列 cartogram／長條。工具：Datawrapper Choropleth、Flourish Projection map、D3（Observable `@d3/choropleth/2`）、R、GeoPandas、Plotly。
- **圖塊地圖（tile map）**：區域代碼＋已正規化指標（每區一列）→ 取得或設計「區域→格座標 row／col」對照（每區一格、座標不重複、外形好認、鄰居盡量相鄰）→ 方塊（好讀好標）或六角（鄰接較完整）→ 順序／發散／質性色＋圖例（ColorBrewer）→ 格內縮寫、特殊格（半區、飛地）另註 → 標題寫「每格一區、格子等大」；缺值灰／斜線。要格數＝人口／選舉人票 → 加權變體（格數加總＝總數，屬 cartogram）。工具：R `statebins`／`geofacet`／R Graph Gallery 州六角；Datawrapper「Switzerland › Cantons (square)」、U.S. hexagons 底圖（electoral college hexagons 為加權版）；Python／Plotly；Tableau（欄列座標＋方塊標記）；D3（Bill Mill grid choropleth、d3kit-gridmap）。
- **點密度圖**：先定一對多（多邊形+計數+Dot Value）或一對一（lat/lon）；點**等大**；圖例必寫「1 點＝N」；校準疏密；一對多用 ArcGIS／Atlas／QGIS，一對一可用 Datawrapper／Flourish 標記（勿 Size by 裝成一對多）。
- **統計變形地圖／比例符號（bubble map）／流量地圖**：面積或符號大小／線寬=資料；對照真實邊界；勿與點密度的等大點疏密混稱；亦勿與**笛卡兒氣泡圖**混（後者圓心在數值軸，見相關／密度）。
- **人口金字塔**：年齡組（可排序）+ 左／右側度量 → 寬或長表 → 左右橫軸同 max → Split Bars＋Mirror（Datawrapper）或 Flourish／Vega 金字塔範本 → 標組距／單位／輪廓形態；勿與龍捲風混用。

## 環境選擇（最短路徑）

| 使用者情境 | 做法 |
|------------|------|
| 已有 Python／JS 專案 | 跟專案依賴，不要無故換棧 |
| 只要一張投影片圖 | 腳本 → png/svg；軸標 zh-TW |

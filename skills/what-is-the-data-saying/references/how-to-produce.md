# 怎麼產出圖表（專案維護者整理）

對齊專案維護者整理的習慣：**先故事句 → 適不適合 → 口述步驟 → 工具路徑 → 自檢**。
面向台灣繁體中文讀者；步驟可口述，程式碼只在使用者要落地實作時再給。

## 每次產出的固定骨架

1. **故事句**（一句）：這張圖要讓讀者看出什麼？
2. **資料契約**：需要哪些欄、型別、單位、加總規則。
3. **口述步驟**（5～8 步）：整理表 → 選編碼 → 排序／分色 → 標註 → 自檢。
4. **工具路徑**：無碼／Python／JS 各給最短路徑；沒有原生圖種要誠實說。
5. **自檢**：讀者能否回答故事句？會不會跟易混圖種搞錯？

## 共通產出規則

- 標題：`主結論或主題 — 時間範圍`
- 圖腳：`資料來源：…；單位：…；備註：…`
- 數字未核實寫「未核」；不要發明連結或案例數字
- 軸與圖例 zh-TW；變數名可 EN
- 靜態簡報：少系列、大字；互動：hover 細節、下鑽
- 避免：3D、無說明雙 Y 軸、彩虹無序類別色、把面積當精確比較卻不給表

## 依任務的口述要點（摘要）

完整 pattern 與 checklist 在 `examples/`。此處只留最短「動手順序」。

### 比較／差距

- **長條**：聚合 → 排序（除非固有序）→ 水平長標籤 → 標單位。
- **棒棒糖圖**：類別 + 單值 → 定基線語意（0／目標／平均）→ 無固有序就依數值排序 → 細莖+末端點（長標籤用水平）→ 少數強調色其餘灰；勿自稱 Datawrapper 原生 Lollipop（近路 Dot Plot；雙端＝Range／啞鈴）。
- **啞鈴**：類別 + 兩個同單位數值 → 兩點+連線 → 按差距排序 → 兩端分色圖例寫死。
- **坡度圖**：確認只要兩期 → 左右同尺 → 線=實體 → 升／降分色可選 → 標註誰升最快。
- **子彈圖**：實際棒 + 目標垂線 + 2～5 段質性底色（同色相深淺）→ 多指標對齊軸。

### 趨勢／排名／組成隨時間

- **折線**：長表 time+value(+series) → 少系列單圖，多系列小多圖。
- **凹凸圖**：每期內排名 → Y 軸名次反向（1 在上）→ 線交叉=超車。
- **河流圖（溪流圖／ThemeRiver）**：time+category+非負量（長或寬表）→ 先貼零堆疊面積對照 → 再切 stream／中軸／wiggle → 類別少、色差夠 → 互動補數值；不強求讀 Y 刻度；負值勿硬套。

### 分布

- **箱形圖**：類別+數值 → 箱＝IQR、中線＝中位數、鬚規則寫清（常 1.5×IQR）、點＝離群；可選平均菱形（≠ 中位）；標各組 n=；並排比多組摘要。Datawrapper **無**原生箱形；要密度／雙峰改小提琴／雨雲；要每點改蜂群。
- **蜂群**：數值軸=真值，另一軸只為避撞 → 保留點身份。
- **小提琴**：類別+數值 → 鏡射密度 + 建議內嵌盒／中位 → 標 n=。
- **雨雲**：半小提琴 + 原始點 + 箱／摘要三件疊加。
- **山脊**：多組密度上下錯位微疊 → 看眾數漂移／雙峰。

### 相關／密度

- **散點**：兩數值；可加趨勢／分組色。
- **氣泡圖**：entity＋x＋y＋size（非負）→ **面積**映射第三量級（勿映半徑／直徑）→ size 圖例必備 → 半透明防重疊 → 只標少數離群；Datawrapper＝Scatter 綁 size（無獨立 Bubble）；第三維要精準排名改長條／棒棒糖；地理分布改 bubble map。
- **矩陣熱圖（heatmap）**：樞紐成列 × 欄 → 一個值 → 各欄尺度差大就依欄／列正規化（圖注寫明）→ 循序色階（單向）或發散色階（有中點，如相關係數 0）；Viridis 類或 ColorBrewer，不用彩虹 → 缺值獨立樣式＋圖例 → 固定順序軸保持原序，要看相似才分群重排（clustermap＋樹狀圖）→ 格子少格內標數字、格子多靠圖例＋懸停。工具：R（ggplot2 `geom_tile`、lattice `levelplot`、基本 `heatmap()`）；Python（Seaborn `heatmap`／`clustermap`、Plotly）；D3 Graph Gallery；Flourish Heatmaps；Highcharts。Datawrapper 本輪查無熱圖專頁，不宣稱原生。日曆版面 → 日曆熱力；節點 × 節點 → 鄰接矩陣。
- **六角分箱／等高線**：點夠多且重疊才用；交代 bin／帶寬；對參數敏感要誠實講。
- **連接散點（型 B）**：X、Y 都是量測，時間只決定連線順序；找 loop／滯後。
- **火山圖（volcano plot；差異分析）**：確認故事是「大量特徵差異結果的優先排序」（任意兩欄 → 散點；橫軸位置 → 曼哈頓圖）→ 表：特徵＋log2 倍數變化＋原始／校正後 p 值，對比方向寫進圖說 → 縱軸 −log10 p，軸標題寫明原始或校正後 → 分析前定倍數與顯著性門檻（範例，不是標準；如 q < 0.05 且 |log2FC| ≥ 1、padj < 0.05 且 0.58），畫水平／垂直虛線 → 三色或四色著色、圖例寫門檻 → 只標要討論的特徵、加引線 → 檢查「倍數大但不顯著」「很顯著但倍數近 0」→ 必要時並列 MA 圖。工具：EnhancedVolcano（Bioconductor，GPL 第 3 版，預設四色；手冊預設 pCutoff 1e-05、FCcutoff 1）；ggplot2＋ggrepel；上游 DESeq2（`lfcThreshold`）、apeglm 收縮；Plotly Python（Dash Bio VolcanoPlot；R 語言版專頁不存在）；Galaxy；Seaborn、Matplotlib 無專屬範例、用散點組裝。
- **曼哈頓圖（Manhattan plot；全基因組關聯）**：確認故事是「關聯訊號落在基因組哪裡、多強」（橫軸效應量 → 火山圖；整體膨脹 → QQ 圖；單一峰值 → LocusZoom 圖）→ 表：標記編號、染色體、位置、p 值；性狀定義、樣本、多重檢定策略寫進圖說 → 縱軸 −log10(p)（用校正後 p 或 q 值要寫明）→ 事先約定門檻並畫線標數值（範例，不是標準；如 5×10⁻⁸≈7.30、提示性 1×10⁻⁵＝5 為工具預設）→ 染色體從 1 起算、依位置排序累加、相鄰交替色、軸標題寫人話 → 只標要討論的峰值 → 線性／環狀／互動；兩性狀用邁阿密圖（上下鏡像）→ 同頁並陳 QQ 圖 → 鎖定尖塔再畫 LocusZoom 圖（`examples/locuszoom.md`）。工具：qqman（R，GPL-3）；CMplot（R，GPL (≥ 2)，線性／環狀／多性狀）；Dash Bio `ManhattanPlot`（Python，MIT）；Matplotlib、ggplot2 手工拼；miami_generator（邁阿密圖）。manhattanly（MIT）已於 2025-06-13 自 CRAN 下架，不當目前推薦。
- **MA 圖（MA plot；平均－差值圖，診斷）**：確認故事是「在什麼豐度層級上變、正規化或收縮是否異常」（候選排序 → 火山圖；橫軸位置 → 曼哈頓圖）→ 表：特徵＋A（平均表現／`baseMean`）＋M（`log2FoldChange`）；要著色再加 p 值或 q 值 → 橫軸 A（多用對數刻度）、縱軸 M（底數一致）、畫 M＝0 線 → 顏色意義寫進圖例（檢定結果 vs 單純 |M| 門檻；門檻為範例，不是標準，如 padj < 0.1〔DESeq2 預設〕、padj < 0.05 且 |LFC| > 1）→ 未收縮與 `lfcShrink` 收縮後並陳（預設不改 p 值，顯著點只是被拉向零，此為推論；收縮是偏向零的估計，不是真值）→ 讀圖：是否以 M＝0 為中心（「多數基因沒差異」是假設）→ 低 A 區喇叭口 → 顯著點落在哪段豐度。RA 圖＝整數計數版，R 同樣放縱軸，用 ε 納入單邊為零的點；Bland–Altman 用原尺度，見 `examples/bland-altman.md`（兩者用途不同，不是同一種圖）。工具：DESeq2 `plotMA`／`lfcShrink`（apeglm、normal、ashr）；limma／edgeR `plotMD`；Glimma 互動；ggplot2、Matplotlib 手作。
- **QQ 圖（Q–Q plot；分位數對分位數）**：確認故事是「分布形狀像不像參考分布／兩批像不像」（累積機率曲線 → P–P 圖〔`examples/pp-plot.md`〕；位置 → 曼哈頓圖）→ 選變體：常態 QQ、兩樣本 QQ、GWAS 風格（期望對觀察 −log10 p）、殘差 QQ → 排序後取同一累積比例（如 (i − 0.5) / n；兩樣本各取 0.05 到 0.95）→ 畫點與參考線，**註明線是 y = x、四分位線或擬合線**（範例，不是標準）→ 軸標題寫清楚理論或樣本在哪軸 → 讀圖：貼 y = x 才是分布相近，貼任意直線只是線性關係；位移＝平移、尺度＝斜率、彎曲＝形狀不同；右偏、厚尾（S 形）、短尾（反向 S 形）、離群值；圖注寫「提示，不是證明，沒有 p 值」，小樣本加提醒。GWAS 風格並陳曼哈頓圖，λ 若報告需另核並註明所用門檻（無單一官方值）。工具：qqman `qq()`（只畫圖，不算 λ）；statsmodels `qqplot`；ggplot2 `geom_qq`／`geom_qq_line`；R `qqnorm`／`qqline`、car `qqPlot`；SciPy `probplot` 畫的是機率圖，不是 QQ 圖。
- **P–P 圖（P–P plot；機率—機率圖）**：確認故事是「同一個數值上，兩邊的累積機率像不像」（同一個累積機率上比數值、講尾巴 → QQ 圖；軸是數值的 NIST「Probability Plot」或 SciPy `probplot` → 不是 P–P）→ 先說清楚比較對象（樣本對理論，或樣本 A 對樣本 B）；理論 CDF 必須完全指定（位置、尺度、形狀或寫明由資料估計）→ 表：至少一欄可排序數量，記 n → 排序並算繪點位置（i/n、(i−0.5)/n、i/(n+1) 擇一，**圖註寫公式**；範例，不是標準）→ 代入理論 CDF（兩樣本法則改在共用數值上讀兩邊的經驗 CDF，兩批位置要相近）→ 畫在邊長為 1 的正方形：兩軸 0 到 1、(0,0)–(1,1) 對角線、**等軸比例**（否則對角線不是 45°）、**圖題寫哪個軸放誰**（本 repo 慣例橫軸理論、縱軸樣本；換軸會鏡射）→ 讀圖：是否貼線 → 彎曲在哪一段機率 → 是否過 (0.5, 0.5)（中位數是否相同）→ 是否貼邊（位置差太遠）→ 中央較敏感、尾部被壓縮（定性說法，不是定理），講尾巴並陳 QQ 圖；「大致貼線」不等於相同，不能取代正式適配度檢定。工具：statsmodels `ProbPlot.ppplot`（0.15.0；軸標與實際內容相反）；reliability `PP_plot_parametric`／`PP_plot_semiparametric`（LGPL 3.0）；Statistica、SAS；Matplotlib 手作。GeostatsGuy 教材圖為 CC BY-NC-ND 4.0。
- **Bland–Altman 圖（Bland–Altman plot；差值圖）**：確認故事是「兩種量測方法一致嗎、能不能互換」且資料是同一批樣本的配對連續量測（沒有配對、只有類別 → 不適用；兩獨立組的差 → Gardner–Altman 圖；豐度與倍數 → MA 圖）→ 表：一列一對，method_a、method_b，**先決定差值方向並寫進圖題**（本 repo 練習資料為方法 B 減方法 A）→ 算差值與兩方法平均，橫軸平均、縱軸差值 → 畫平均差線、平均差 ± 1.96 SD 兩條一致性界限（範例，不是標準；1986 年原文用 2 倍）與 0 線 → 加平均差與兩條界限各自的 95% 信賴區間 → **事先**訂可接受範圍（臨床或專業判斷，不是統計決定；本 repo 示範用 ±8 是假設）→ 檢查**差值**是否近似常態（非常態改用第 2.5／97.5 百分位數）、散布是否隨大小改變（扇形 → 百分比差異、取對數或迴歸式界限）、走勢是否傾斜（比例性偏差）→ 讀圖：平均差離 0 嗎、扇形、傾斜、離群配對；界限外有少數點正常，相關高不代表一致；它不能證明新方法「準確」。工具：statsmodels `mean_diff_plot`；pingouin `plot_blandaltman`；R BlandAltmanLeh、blandr；MedCalc；Matplotlib 手作。
- **LocusZoom 圖（LocusZoom plot；區域關聯圖）**：確認故事是「這座尖塔底下是誰、旁邊的點是跟著跑還是另一個訊號」且資料是 GWAS 或全基因組掃描、已有曼哈頓圖找出區間（全基因組哪裡有峰 → 曼哈頓圖；p 值整體膨脹 → QQ 圖；沒有座標與 p 值 → 資料前提不足）→ 記錄性狀、分析版本與基因組組建（GRCh37／GRCh38）→ 選定區間（範例：領先變異左右各數百 kb、基因加側翼、直接指定座標；通常小於 1 Mb；經驗法則）→ 選領先（lead）變異（預設區間內最顯著；條件分析後改用屬推論；**不寫「鉛變體」**）→ 表：每個變異至少位置與 p 值 → 向參考面板查 r²（**圖註寫參考面板與族群**，換族群顏色會變）→ 主面板橫軸位置、縱軸 −log10(p)、依 r² 分級著色（紅 >0.8、橙 0.6–0.8、綠 0.4–0.6、淺藍 0.2–0.4、深藍 <0.2、領先變異紫色；範例，不是標準）、虛線 7.3＝5×10⁻⁸（常用慣例，圖例要寫）→ 下方基因軌、可選重組率（右軸單位寫清楚：cM/Mb 或 %）→ 讀圖：領先變異是不是最高點 → 紅橙一叢與單一訊號一致但不能證明 → 低 LD 的高處第二個峰需條件分析 → 基因軌只是候選假設的起點；領先變異不等於因果，共定位、精細定位、條件分析不是這張圖。工具：LocusZoom.js、my.locuszoom.org；R locuszoomr（顏色與右軸單位與 LocusZoom.js 不同）；locuscomparer（共定位，只記名）；Matplotlib 手作。Pruim 2010 的圖僅限非商業使用。
- **核型圖／染色體帶型示意圖（karyotype／ideogram）**：確認故事是「整套染色體數目與排列」、「單條加某區間」或「全基因體骨架上疊資料」三選一，不要混成一張過載圖（關聯尖峰 → 曼哈頓圖；區間關聯細讀 → LocusZoom；環狀多軌 → Circos；只有長度 → 長條圖）→ 選定物種與基因體版本，帶型表與標註座標同一版本並寫進圖註 → 取 cytoBand／ideogram 表或教材提供的示意帶型（標來源；人類 46 條＝23 對）→ 依長度比例畫染色體條，標著絲點與 p（上）、q（下），需要辨認時加 G 帶深淺；成對核型對齊著絲點列；帶號由著絲點往端粒遞增 → 再疊區間、基因、拷貝數或密度，缺失或重複的色框只框有變化的那一條 → 顏色隨工具，圖例寫清楚；圖題註明「示意，不是病人照片，標註不等於診斷」 → 讀圖順序：著絲點 → p、q → 帶型地標 → 色塊區間 → 對回報告文字或 ISCN 帶號。不要說成「karyogram＝照片、ideogram＝示意圖」（維基百科視為同義詞）。工具：Ideogram.js（網頁，CC0-1.0）、karyoploteR（R／Bioconductor）、IdeoViz（GPL-2）、RIdeogram、NCBI Genome Data Viewer、UCSC Genome Browser 帶型軌。
- **森林圖（forest plot）**：先問這些研究能不能合併；整理研究名、效應量、信賴區間下限與上限、權重（比值類先取自然對數；只有區間時用 (ln 上限 − ln 下限) ÷ (2 × 1.96) 反推標準誤）；選固定或隨機效應並把 τ² 估計法寫進圖註（statsmodels 預設 Paule–Mandel，DL 要設 `method_re='dl'`）；比值畫對數軸、無效線在 1，差值線性軸、無效線在 0；方塊**面積**∝權重，橫線畫 95% 信賴區間，菱形寬度＝合併信賴區間，底部寫 Q、df、I²、τ²；I² 分級是重疊的粗略說法，不要硬分類。工具：R 的 metafor／meta／forestplot／forestploter、Python 的 statsmodels `plot_forest`（zEpid 為森林圖式效應量圖）、RevMan、jamovi MAJOR（第三方）；Excel 可用散佈圖加自訂誤差線（誤差線值是與中心點的差距；方塊大小要手動調，邊長∝權重平方根是推論）；Google 試算表的誤差線沒有逐項自訂，不適用。統合分析的漏斗圖（檢查發表偏差，至少約 10 項）和商業漏斗圖是兩種不同的圖。詳見 `examples/forest-plot.md`。
- **地平線圖（horizon chart）**：先確認有「很多條」對齊時間軸的序列、列高有限；準備長表（時間、序列、數值）並決定基準，圖說寫清楚；每條想成相對基準的面積圖；選鏡射（負值翻到基準上方、色相分正負）或 offset（負值從條頂往下長）；帶寬＝想蓋住的最大偏離 ÷ 帶數，以 2 帶為主，要跨列比較就所有列共用同一個帶寬；切帶疊回同一條矮條，越深離基準越遠；垂直排成小多圖、共用時間軸、左側放序列名；圖例第一句寫「顏色深度＝層數＝幅度」，顏色以圖例為準；精確數值留給游標或單條折線；矮條高度不是真實振幅。工具：JavaScript 的 Cubism.js、d3-horizon-chart、d3-horizon；R 的 latticeExtra `horizonplot`、ggHoriPlot；不寫程式可看 RAWGraphs 教學頁（CC BY-NC-SA 4.0，僅限非商業）；各工具預設鏡射或 offset 不同，先查設定。詳見 `examples/horizon-chart.md`。
- **柏拉圖（Pareto chart）**：先決定分類（類別不重疊）、期間、用件數還是金額；彙總成每類一列，由大到小排序，「其他」通常放最右；算累計百分比（累計 ÷ 總數）；畫直條加折線，折線放右軸 0–100%，**左軸最大值設成總數**；可加 80% 參考線但只當參考，讀法是看累計線第一次到達或越過 80% 是第幾項；換成金額、改善後各重畫一次。工具：Excel 內建 Pareto 圖（插入 → 插入統計圖表 → 直方圖區的 Pareto；自動重排、固定不了「其他」；版本說法見範例）；舊版或 Google 試算表用組合圖（官方圖表清單沒有 Pareto，這是推論）；Minitab 的 Stat → Quality Tools → Pareto Chart；R 的 qcc `pareto.chart`。素材包沒有在真機上逐一實測。詳見 `examples/pareto-chart.md`。
- **管制圖（control chart）**：先決定量什麼、多久取一次、子組怎麼組成，依資料型態選圖（X̄–R、X̄–S、I–MR、p、np、c、u）；蒐集一段大致穩定期間的資料估中心線與上下管制界限（常見約 3σ，界限來自流程資料、不是規格；公式與常數連前提與來源一起寫，不憑記憶）；事先約定判異規則（Western Electric 或 Nelson，連續同側分別是 8 點與 9 點）；把點依時間順序連線；失控就找特殊原因，消除後進入新穩定態才重算界限，不要太常改；圖說寫清楚界限來源、用哪一套規則、點數怎麼數，標紅的點和圖說一致；中心線、管制界限、規格線用不同線型。素材包沒有實測任何軟體，工具細節以各家說明為準。詳見 `examples/control-chart.md`。
- **洛倫茲曲線（Lorenz curve，含基尼係數）**：先決定單位與數量（非負、可加總）與口徑（稅前後、個人或家戶、年份）；把單位由小到大排序；算累計——橫軸＝前面單位數 ÷ 總單位數，縱軸＝這些單位合計 ÷ 全體合計，從 (0,0) 到 (100%,100%)；加對角線（必要時疊一人全拿的參考線）；讀點時寫區間（「最貧 40%（前 4 戶）累計 14%」）；比較兩群體疊同一張圖，先看有沒有交叉；單位少時可用折線下面積算基尼（G＝1−2B），**註明有沒有小樣本修正**（乘 n／(n−1)，10 戶約差 11%），並保留整條曲線或輔以分位份額表（最貧 50%、最富 10%）；圖說標清口徑，字母 A、B 標在區域內。素材包沒有實測任何軟體，工具細節以各家說明為準。與柏拉圖相通但不同，不是同一種圖。詳見 `examples/lorenz-curve.md`。
- **馬雷圖（Marey chart／列車運行圖）**：確認有一條一維路線，列出沿線站點與實際里程（路網就挑一條路線、一個方向）；整理每班車在每站的到站與離站時刻（起點只有離站、終點只有到站；計畫時刻表或車輛定位換算的實際時刻都可）；決定軸向（時間橫軸、站點縱軸，或反過來）並在軸標寫清楚；站點依實際距離排，不要等距；每班車畫一條線（到站→離站→下一站到站，水平段＝停站）；用顏色或線型分方向、車種、計畫對實際；標出超車點、交會點（站內或站間）、誤點擴大段、串車開始的站，單線路線標出可會車的站；太密就拆成尖峰、方向或車種分圖，或全天總覽加放大圖；圖說寫精確時刻與位置、圖面「約」值附精確值。素材包沒有實測任何軟體（試算表散佈圖加連線是素材包的說法，未實測；D3、gtfs-marey、gtfs-to-chart 只列連結）。歷史說法用限定語。詳見 `examples/marey-chart.md`。
- **存活曲線（Kaplan–Meier）**：定義起點、事件與截止日；整理每人觀察時間與狀態（1／0），比較時加組別；只在事件時間把存活比例乘上（1 − 事件數 ÷ 風險人數），設限者離開後才扣分母，同日設限在事件之後離開；畫成階梯並標設限短直線；加 95% 信賴區間帶（常用 Greenwood）與圖下風險人數表（KMunicate 建議連累計設限與事件）；標中位數與關鍵時間點存活比例；兩組比較寫明風險比誰除以誰、對數等級 P 值與區間；交叉時加分段；尾端人少截掉或改淡色；縱軸截斷要明講；有競爭風險改畫累積發生率。素材包沒有實測任何軟體（R survival／survminer、Python lifelines 只列連結）。歷史用 Stalpers 2018 限定語。詳見 `examples/kaplan-meier-survival.md`。
- **游泳圖（swimmer plot）**：每人一列整理開始、時長、停止原因、是否仍在與事件時間；一人一條橫棒、依時長排序（最長在上或在下要一致）；顏色或分面表示組別；符號標第一次反應、完全反應、惡化，停止原因用棒尾記號，仍在治療畫箭頭；圖說寫資料截止日、符號圖例、排序規則與挑選條件；可加反應持續時間（另一色段）；超過約 50 人改 Kaplan–Meier 或分面；與腫瘤學瀑布圖並列時共用受試者順序。工具：SAS SGPLOT、R swimplot／ggswim（ggswim 從 GitHub 安裝）等只列連結，本 repo 未實測。詳見 `examples/swimmer-plot.md`。
- **千層麵圖（lasagna plot，暫譯）**：確認資料是多個個體 × 共同時間點（不一致先決定網格）；整理成寬表，一列一人、一欄一時間點，缺值保留空格（不補 0、不刪欄）；決定排序（看個人用整列排序，如個人平均；有分組先分組再組內排序；看各時間點分布用欄內排序；找相似型態用分群＋樹狀圖），並寫在圖上；連續值用單色由淺到深、有自然中點用發散色階、類別用易區分的顏色，避免彩虹色階，所有面板同一範圍；缺值用灰色或灰底斜線並進圖例；每列通常 10 像素以上（Wicklin 2016），人多分組、抽樣、分頁或改比例版；下方加每組每時間點平均折線或比例表，進位方式一致。工具：Excel、Tableau、SAS、Stata、R longCatEDA／iglu／lasagnar、medplot 只列文獻所見，本 repo 未實測；Datawrapper、Flourish 範本未核。詳見 `examples/lasagna-plot.md`。
- **遞迴圖（recurrence plot，暫譯）**：確認等距時間序列；先標準化；決定延遲嵌入（m、τ）或不嵌入；算每兩個狀態的距離得到 N×N 表；選門檻 ε（固定遞迴率、距離百分比等），**一定要試幾個**；畫黑白方陣，標長度、ε、m、τ、距離算法與「黑＝遞迴」圖例，上方或左邊對齊原始序列；需要數字再做 RQA（比較時固定同一套設定）；兩條序列用交叉遞迴圖。工具：Python pyts／PyRQA、R crqa、Marwan 網站工具列表只列連結，本 repo 未實測。非商業授權來源（recurrence-plot.tk、Marwan 2007／2023 arXiv）只連不嵌。詳見 `examples/recurrence-plot.md`。

### 階層組成

- **共同**：葉非負值；父=子加總；層順序=深度／圈順序。
- **冰柱**：直角 partition，好標字、深層較不易被徑向擠壓；Flourish 常無原生冰柱。≠ 火焰圖（堆疊取樣）。
- **火焰圖（flame graph；效能剖面，非組成）**：確認故事是熱路徑不是時間順序 → 取帶堆疊的剖面（Linux perf／eBPF、DTrace、產品化剖析器、語言取樣器；符號齊備）→ 收合成 `根;…;葉 計數` → 標準（根在下）或冰柱布局（根在上）→ 色票寫明（CPU 隨機暖色無資料意義；Memory 綠；Differential 紅增藍減）→ 互動：懸停、點選放大、搜尋累計 → 有週期／突發先用 FlameScope 挑時段 → 讀法：最寬頂緣葉框 → 祖先 → 搜尋累加 → 對帳計數表；圖注寫「橫向不是時間」與取樣條件。要時間順序 → 火焰時序圖（Chrome 開發者工具 Performance、speedscope Time Order）。工具：`brendangregg/FlameGraph`（互動 SVG）、`d3-flame-graph`、speedscope、FlameScope。
- **旭日**：同一套 partition 改環帶；小塊靠 hover／下鑽。
- **矩形樹狀**：嵌套矩形鋪滿；葉面積∝值。
- **圓堆**：嵌套圓；面積弱於長度，精準比請旁表。
- **Voronoi 樹狀**：凸多邊形鋪滿；圖注寫「不是地圖」。

### 流動／階段

- **瀑布**：起點 + 有符號增量 + 終點；落地柱 vs 浮空柱；connector；正負分色。
- **漏斗**：有序階段 + 通過量；後階不大於前階；標轉換率與瓶頸。
- **桑基**：來源、去向、非負流量；帶寬=流量；弱邊可裁。
- **沖積**：2～5 有序階段重分組；塊=當階大小，帶=過渡量。
- **弦圖**：方陣或來源/去向/值；圓上節點+帶；裁弱邊、靠 hover。
- **Circos（環狀多軌圖）**：確認故事是「長參考軸＋多層訊號＋對位」（只有類別流量 → 弦圖）→ 扇區表（清單、長度、順序、方向）→ 軌道表（扇區＋起訖位置＋值／類別，同角度對齊）→ 連線表（兩端位置、方向、類型、寬度；先篩弱／短連線、調透明度）→ 由外而內：染色體示意圖 → 軌道 → 連線；執行期規則上色（不改原資料）→ 稀疏熱點局部放大／軸斷點 → 輸出 PNG／SVG，向量圖再微調標籤圖例；圖旁三句讀法。工具：官方 Circos（Perl 命令列、純文字設定檔；GPL 第 3 版）；R circlize、Python pyCirclize（MIT；同家族實作，不是官方版，圖注要寫明）。

### 類別交叉／集合／市場區隔組成

- **馬賽克**：交叉表；欄寬=邊際、格高=條件、面積=聯合；主線＝列聯／獨立性（殘差著色可選）。勿與商用 Marimekko 混稱。
- **馬里梅可／Mekko**：外層區隔 + 內層組成 + 可加總量 → 選百分比軸或絕對值軸 → 欄寬＝區隔總量占比、色帶高＝區內占比（或絕對堆疊）→ 外／內排序統一、細項併「其他」→ 大色塊直標、細帶圖例／hover；Flourish／think-cell／Qlik／Domo／Mekko Graphics 有原生；**Datawrapper 無原生**；Excel 常靠堆疊面積＋累積寬度。
- **平行集合**：多類別軸 + 頻率帶；可拖軸。
- **UpSet**：多集合交集；集合多時勝過 Venn。

### 網路

- **力導向**：節點+邊；先過濾規模；位置≠地理；標樞紐即可。
- **弧線**：節點排一條線（順序最關鍵）+ 弧=邊。
- **鄰接矩陣**：同一批節點×節點；**排序**後看團。
- **蜂巢圖**：放射軸分區規則要講得出；用來比較多張網。
- **HEB**：階層樹 + 葉↔葉連線；沿共同祖先捆線；缺一邊就不要畫。
- **BioFabric（生物織布圖，暫譯）**：確認故事是梳毛球／看邊與連線型態（不是流量寬度）→ 邊表 source／target（有向保留方向；類型、條件、時間、權重另欄；官方工具常用定位字元分隔／`.sif` 風格匯入）→ 定列序（度數、名稱或連通性相似）→ 定欄序（先來源列再目標列，讓邊扇成楔形；有連結分組先按組分塊）→ 每節點一條水平線、每邊一條垂直線段、端點標記 → 太寬用陰影連結、節點區底色、子集視圖／巡覽 → 圖例寫「列＝實體、垂直線＝關係」＋分組／方向 → 精確數字另附計數表。工具：BioFabric Java 桌面版（`wjrl/BioFabric`，LGPL 2.1）、RBioFabric（`wjrl/RBioFabric`，未上架 CRAN，從 GitHub 裝）、D3BioFabric（`wjrl/D3BioFabric`）、yFiles（產品說明頁）。

### 地理／時間骨架／剖面

- **日曆熱力**：聚合到每日一值；週×星期；寫週起始與時區。
- **螺旋圖（spiral plot）**：確認需要「週期對齊＋長序列」（只看趨勢用折線）→ 定一圈＝一個週期與方向（中心較早、外圈較新），寫在圖上 → 排序、缺值、必要時彙總到週期顆粒度 → 軌道編碼：長條／棒棒糖（振幅高峰）、折線／面積（連續起伏）、螺旋熱圖色塊（分級強度）、地平線（進階）→ 外圈角度刻度＋數值圖例（單位；氣候異常寫基準期）→ 圈太密就縮年份、拉大圈距或做動畫 → 提醒外圈弧長較長，精確差值另附對照表或線性局部圖。工具：R `spiralize`；D3 社群實作（tomshanley d3-spiral-heatmap、Condegram gist）；氣候螺旋範本 Ed Hawkins Climate Visuals、NASA SVS 5190。data-to-viz／Flourish／R・Python Graph Gallery 無專頁。
- **甘特**：任務+開始+結束；少畫依賴箭頭。
- **雷達**：軸必須可比、同尺；系列少；面積≠總分。
- **平行座標**：多連續軸；先縮放；軸順序影響可讀性。
- **等值區域圖（choropleth）**：區域代碼＋已正規化指標（分子／分母→比率、每十萬人、每面積）→ 對上邊界檔（同編碼、同年份，檢查未匹配）→ 連續或分級（寫明分位數／等距／自然斷點）→ 順序或發散色（中心值寫明；ColorBrewer）→ 缺值灰／斜線＋「無資料」→ 只標要點名的區；總量改比例符號地圖；大面積低人口偏誤要註明或並列 cartogram／長條。工具：Datawrapper Choropleth、Flourish Projection map、D3（Observable `@d3/choropleth/2`）、R、GeoPandas、Plotly。
- **圖塊地圖（tile map）**：區域代碼＋已正規化指標（每區一列）→ 取得或設計「區域→格座標 row／col」對照（每區一格、座標不重複、外形好認、鄰居盡量相鄰）→ 方塊（好讀好標）或六角（鄰接較完整）→ 順序／發散／質性色＋圖例（ColorBrewer）→ 格內縮寫、特殊格（半區、飛地）另註 → 標題寫「每格一區、格子等大」；缺值灰／斜線。要格數＝人口／選舉人票 → 加權變體（格數加總＝總數，屬 cartogram）。工具：R `statebins`／`geofacet`／R Graph Gallery 州六角；Datawrapper「Switzerland › Cantons (square)」、U.S. hexagons 底圖（electoral college hexagons 為加權版）；Python／Plotly；Tableau（欄列座標＋方塊標記）；D3（Bill Mill grid choropleth、d3kit-gridmap）。
- **點密度圖**：先定一對多（多邊形+計數+Dot Value）或一對一（lat/lon）；點**等大**；圖例必寫「1 點＝N」；校準疏密；一對多用 ArcGIS／Atlas／QGIS，一對一可用 Datawrapper／Flourish 標記（勿 Size by 裝成一對多）。
- **統計變形地圖／比例符號（bubble map）／流量地圖**：面積或符號大小／線寬=資料；對照真實邊界；勿與點密度的等大點疏密混稱；亦勿與**笛卡兒氣泡圖**混（後者圓心在數值軸，見相關／密度）。
- **人口金字塔**：年齡組（可排序）+ 左／右側度量 → 寬或長表 → 左右橫軸同 max → Split Bars＋Mirror（Datawrapper）或 Flourish／Vega 金字塔範本 → 標組距／單位／輪廓形態；勿與龍捲風混用。

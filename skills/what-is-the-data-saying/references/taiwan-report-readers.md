# Taiwan report readers（台灣報表讀者）

User-facing labels, captions, and takeaways: **Traditional Chinese (Taiwan)**.

## Language & labels

- 用「營收／毛利／年增／月增／市佔／科目／縣市」，避免中國大陸用語（例如「數據」可保留，但「信息／視頻」等不必要時改寫）。
- 數字：千分位逗號；百分比用 `%`；貨幣標 `新台幣` / `TWD` / `千元`（與來源一致）。
- 時間：`2025年`、`2025/03`、`2025 Q1`；財報常用「累季／同期」。
- 圖標題公式：`主結論或主題 — 時間範圍`（例：`各產品線營收比較 — 2025 H1`）。
- 圖脚下註：`資料來源：…；單位：…；備註：…`。

## Common TW report contexts

| Context | Reader expectation |
|---------|-------------------|
| 董事會／經營會議 | 少圖、大字、結論句在標題或首行 |
| 財務／會計 | 可對到科目與期間；保留 table |
| 公部門／計畫書 | 清楚單位、基期、YoY；避免過度裝飾 |
| 產品／成長 | 趨勢 + 結構（誰貢獻成長） |

## Pitfalls

- 把「萬元／千元」軸標漏掉 → 誤讀數量級。
- YoY 與絕對值混在雙軸卻不說明。
- 類別名過長：改水平 bar 或縮寫 + 圖例全名。
- 英文套表直接給台灣讀者：軸與標題至少中文化。

## Takeaway sentence pattern

`{誰／什麼} 在 {期間} {升／降／佔} {數字}，主因是 {一句}。`
